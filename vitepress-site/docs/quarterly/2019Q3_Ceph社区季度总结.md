# Ceph 社区 2019Q3 季度总结报告

## 1. 主要活动和重点议题

### 1.1 Ceph 性能会议

* **SATA SSD 利用率**: 讨论了 SATA SSD 的利用率问题，指出其接近最大吞吐量，具体取决于设备性能和 IO 负载类型。
* **Luminous 代码改进**: 讨论了 Luminous 代码的改进，包括性能提升和功能增强。
* **CLS 代码中的过滤功能**: 讨论了在 OSD 中的 CLS 代码中实现过滤功能的改进，包括对性能提升和减少网络使用量的影响。
* **bucket reshaping 性能**: 讨论了 bucket reshaping 的性能，包括在 resharding 过程中允许客户端写入和优化锁定机制。
* **4K 金属块大小**: 讨论了在 OMAP 中使用 4K 金属块大小对性能和空间利用率的影响。
* **小对象在 OMAP 中的存储**: 讨论了在 OMAP 中使用小对象（小于 4K）存储的改进，包括对性能和空间利用率的影响。

### 1.2 Ceph 科学用户组会议

* **Ceph 使用案例**: 分享了来自全球多个机构的 Ceph 用户使用案例和经验，包括 OpenStack、高性能计算、数据备份等。
* **Ceph 性能优化和问题解决**: 讨论了 Ceph 性能优化方法，例如使用 NVMe 硬盘、优化存储池配置、使用性能监控工具等，并分享了一些常见问题的解决方法。
* **Ceph 未来发展方向**: 讨论了 Ceph 的未来发展方向，例如支持更多协议、提高性能、增强安全性等。
* **Ceph 社区建设和活动**: 讨论了如何加强 Ceph 社区建设，例如组织线上和线下活动、建立用户交流平台等，并计划在瑞士日内瓦举办 Ceph Day 活动。

## 2. 技术发展和创新亮点

* **Luminous 代码改进**: 提升了 Ceph 的性能和功能，包括改进了数据放置算法、优化了存储池管理、增加了新的故障检测机制等。
* **CLS 代码中的过滤功能**: 通过过滤功能，可以减少网络使用量，提高 Ceph 的性能和可扩展性。
* **bucket reshaping 性能优化**: 通过优化 resharding 过程，提高了 Ceph 的性能和可靠性。
* **OMAP 中的小对象存储改进**: 通过优化小对象存储，提高了 Ceph 的性能和空间利用率。

## 3. 重要的决策和里程碑

* **推进 Luminous 代码改进**: 将 Luminous 代码迁移到 Nautilus 代码库进行对比测试。
* **评估 CLS 代码中过滤功能的性能提升和网络使用量减少**。
* **研究 bucket resharding 的性能和优化锁定机制**。
* **在 OMAP 中使用 4K 金属块大小进行测试，并评估其对性能和空间利用率的影响**。
* **对小对象在 OMAP 中的存储进行改进，并评估其对性能和空间利用率的影响**。

## 4. 社区贡献和合作情况
