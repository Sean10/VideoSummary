# Ceph社区2021年第二季度总结报告

## 1. 本季度Ceph社区的主要活动和重点议题

### 1.1 社区会议

* **Ceph Crimson/SeaStore 2021-06-16**: 会议讨论了设备管理支持、PR审查与更新、单元测试问题、构建问题、Ceph Master分支问题等。
* **Ceph Orchestrator Meeting 2021-04-20**: 会议讨论了Ceph部署、Ganesha NFS服务配置、NVMe over Fabrics实现细节等。
* **CephFS Code Walkthrough: MDSMonitoring**: 会议深入探讨了MDS Monitor的概述、组件和操作、代码实现细节等。
* **Ceph Month 2021: The go-ceph get together BoF**: 会议回顾了GoCeph项目的历史和现状，讨论了项目未来计划和技术发展。
* **Ceph Month 2021: RADOS Update**: 会议介绍了Ceph Pacific版本和Quincy版本的更新，包括可用性增强、质量提升、性能优化等。

### 1.2 社区贡献和合作情况

* **开源软件项目**：Ceph社区持续贡献于多个开源项目，包括Ceph、Rook、Cosbench等。
* **技术论文和博客**：社区成员撰写技术论文和博客，分享Ceph相关知识和经验。
* **会议和研讨会**：社区成员积极参加各种会议和研讨会，分享Ceph的最新进展。
