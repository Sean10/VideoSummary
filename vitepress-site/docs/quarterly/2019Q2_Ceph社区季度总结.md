# Ceph 社区 2019Q2 季度总结报告

## 1. 本季度 Ceph 社区的主要活动和重点议题

**1.1 Ceph BenchOps：简化 Ceph 项目上线流程**

* 由加州大学圣克鲁兹分校的 Eva Jimenez 博士研究生主持。
* 旨在简化学生使用 Ceph（安全存储）的上线和部署流程。
* 使用 GitHub Action 工作流程和容器化技术来简化流程，提高效率和用户体验。

**1.2 探索 Nautilus 中 Surface 的性能限制**

* 由 Red Hat 的 Manoj Pillai 介绍。
* 探讨了 Nautilus 版本中 Surface 的 I/O 性能限制。
* 测试结果表明，Surface 在顺序 I/O 和随机读方面表现出色，但随机写和小型文件 I/O 性能较差。

**1.3 Crimson SeaStor OSD 周会**

* 讨论了 Ceph 项目进展、性能测试、代码审查及后续行动计划。
* 包括 Crimson 项目进展、测试方法、性能改进和代码审查等方面。

**1.4 Per OSD Recovery Bandwidth Control Based on dmClock**

* 由 ZTE 公司的 Xie Xingguo 和 Yan Jun 介绍。
* 提出了基于 dmClock 的云附加存储方法设计、实现和测试。
* 通过控制去重操作的带宽，平衡去重与客户端性能之间的关系。

**1.5 Ceph 对象存储在公共云服务中的应用**

* 由 China Mobile 的 Yu Liyang 介绍。
* 讨论了 Ceph 对象存储在公共云服务中的应用，包括集群扩展、W 模块更新和性能压力。

**1.6 Failing Better - When Not To Ceph and Lessons Learned**

* 由 SUSE 的 Lars Marowsky-Brée 介绍。
* 讨论了 Ceph 的限制和约束，以及如何根据实际需求选择合适的硬件和网络。

**1.7 Unlimited Fileserver with Samba CTDB and CephFS**

* 由 Heinlein Support GmbH 的 Robert Sander 介绍。
* 讨论 Ceph 分布式存储系统在视频会议字幕翻译中的应用与优化。

**1.8 Learn Ceph — For Fun, For Real, For Free!**

* 由 City Network 的 Florian Haas 介绍。
* 介绍了 Ceph 云学院课程更新及用户反馈征集。

**1.9 Rebuilding a Faster OSD with Future**

* 由 Red Hat 的 Kefu Chai 和 Radoslaw Zarzynski 介绍。
* 讨论了 Ceph Crimson 项目进展及未来方向。

**1.10 Ceph Octopus Roadmap Planning series: RADOS**

* 讨论了 Ceph Octopus 版本的更新计划，包括 EC 数据恢复、容量不足警告、自适应恢复设置等。

## 2. 技术发展和创新亮点

**2.1 Crimson 项目**

* 针对 SSD 和 NVMe 接口的优化，提高 I/O 性能。
* 使用用户空间驱动器和无锁设计，避免锁竞争。
* 利用未来存储设备的并行处理能力。

**2.2 Blue Store**

* 基于 RocksDB 构建，提高 Ceph 的性能和效率。
* 支持持久内存，进一步提高性能。

**2.3 CephFS**

* 可扩展的分布式文件系统，支持 POSIX 兼容性。
* 高效的元数据管理，保证数据一致性。

**2.4 RBD**

* 基于 Ceph 的块存储，支持多种存储协议。
* 高效的存储和快照功能，保证数据可靠性。

**2.5 Ceph 消息传递**

* 基于 Seastar 构建，提高 Ceph 的性能和可扩展性。
* 支持异步编程模型，简化开发过程。
