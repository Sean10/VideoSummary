# Ceph 社区 2024Q1 季度总结报告

## 1. 本季度Ceph社区的主要活动和重点议题

本季度，Ceph 社区围绕多个关键议题和功能进行了深入讨论和开发，以下是一些主要活动和重点议题：

- **磁带存储功能请求**：国家太阳能天文台的SEF操作员Joel Davido提出了在对象存储中使用磁带作为存储类的功能请求，会议中对此进行了详细讨论，并决定创建跟踪器票证以跟踪该功能的进展。
- **RGW 重构会议**：多次会议讨论了RGW的重构工作，包括TC崩溃问题、Zipper相关GCK项目、Redis作为消息队列、DDoP问题和通知事件的可见性等多个议题。
- **Ceph 开发者月度会议**：讨论了monit monitor manager输出Network ping stats、NVMe TCP Gateway、端到端追踪等多个技术议题。
- **Ceph 用户月度会议**：介绍了即将完成的《Ceph入门指南》及其相关工作，并讨论了Ceph组件、架构、硬件要求等内容。

## 2. 技术发展和创新亮点

本季度，Ceph 社区在技术发展和创新方面取得了以下亮点：

- **磁带存储功能**：计划将磁带存储作为Ceph对象存储的存储类之一，以降低存储成本并提高长期数据存档的可靠性。
- **RGW重构**：对RGW进行重构，以提高性能和可扩展性，并解决一些已知问题。
- **NVMe TCP Gateway**：引入NVMe-oF技术，实现高性能、低延迟的存储访问。
- **端到端追踪**：实现端到端追踪功能，便于用户监控和调试Ceph集群。

## 3. 重要的决策和里程碑

本季度，Ceph 社区在以下方面取得了重要的决策和里程碑：

- **拒绝TC 2.8版本**：为避免TC崩溃问题，决定在SEF spec文件中拒绝TC 2.8及其所有次要版本。
- **代码冻结**：进行了Squid版本的代码冻结，为后续开发奠定基础。
- **IAM策略限制**：为避免未来可能出现的问题，建议对所有IAM相关元数据设置限制。

## 4. 社区贡献和合作情况

本季度，Ceph 社区在以下方面取得了显著的贡献和合作成果：

- **《Ceph入门指南》**：社区成员共同努力，完成了《Ceph入门指南》的撰写工作。
- **开源项目**：多个开源项目得到了社区成员的支持和贡献，如Cephadm、CephFS、CephMon等。
- **技术讨论**：社区成员在多个技术论坛和会议中积极参与讨论，分享经验和知识。

## 5. 下一季度展望和计划

下一季度，Ceph 社区计划在以下方面开展工作：

- **磁带存储功能**：继续推进磁带存储功能的开发，并在后续版本中实现。
- **RGW重构**：完成RGW重构工作，提高性能和可扩展性。
- **NVMe TCP Gateway**：完成NVMe TCP Gateway的开发和测试。
- **端到端追踪**：完善端到端追踪功能，并确保其在Ceph集群中的稳定运行。
- **社区活动**：举办更多的技术讨论和培训活动，促进社区成员之间的交流和合作。

Ceph 社区将继续致力于推动Ceph技术的发展和创新，为用户提供更高效、可靠的存储解决方案。
