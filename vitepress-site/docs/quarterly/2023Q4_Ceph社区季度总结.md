## Ceph社区 2023 年第四季度总结报告

### 1. 本季度Ceph社区的主要活动和重点议题

本季度，Ceph社区活动频繁，主要集中在以下议题：

- **Ceph RGW 重构会议**：讨论了 RGW（Rados Gateway）的重构工作，包括 IAM、生命周期管理、通知系统、Bucket Notification 和 Multi-Site 支持等。
- **Ceph 开发者月度会议**：针对 Ceph Manager 模块加载问题、审计模块的创建请求、去重功能的改进等议题进行了深入讨论。
- **Ceph 用户 + 开发者月度会议**：聚焦于 Ceph 分布式存储系统的优化与管理，例如 PG Remapper 工具介绍、Ceph Dashboard 的新功能等。

### 2. 技术发展和创新亮点

本季度，Ceph 社区在以下方面取得了显著的技术发展和创新：

- **IAM 和账户管理**：对 IAM 的未来方向进行了讨论，包括账户所有权、使用会计、账户层次结构和配额管理等方面。
- **生命周期管理**：解决了生命周期事件日志记录的问题，并改进了生命周期处理的时间策略。
- **数据去重**：探索了新的去重机制，以提高处理大量重复数据块的效率。
- **配置管理和初始化**：探讨了在区域创建时初始化存储过滤器的配置，以及 JSON 配置的具体格式。

### 3. 重要的决策和里程碑

本季度，Ceph 社区达成以下重要决策和里程碑：

- **账户所有权**：决定所有权的归属将归于根账户，而不是用户。
- **使用会计和配额**：决定在账户级别进行使用会计和配额管理，而不是在用户级别。
- **SNS 主题策略**：计划实现 SNS 主题策略，并通过 RGW 管理命令和 API 来设置。
- **多站点支持**：讨论了关于 Bucket Notification V2 的实现和 Multi-Site 功能的支持。

### 4. 社区贡献和合作情况

本季度，Ceph 社区成员积极贡献，以下为部分亮点：

- **Coverity 项目**：通过 Coverity 工具识别并解决了多个代码问题，提高了代码质量。
- **多站点数据日志和 bi 日志**：解决了数据日志和 bi 日志的竞态条件问题。
- **通知系统**：更新了通知系统，以解决 IAM 策略或通知时可能出现的策略覆盖问题。

### 5. 下一季度的展望和计划

下一季度，Ceph 社区将继续关注以下议题：

- **优化 RGW 功能**：继续推进 RGW 的重构工作，包括 IAM、生命周期管理、通知系统等。
- **提升性能**：针对数据去重、生命周期管理等功能进行性能优化。
- **增强可扩展性**：探索新的数据模型和架构，以提升 Ceph 的可扩展性。
- **加强社区合作**：鼓励更多开发者参与社区，共同推动 Ceph 的发展。

Ceph 社区将继续致力于为用户提供稳定、可靠、高性能的分布式存储解决方案，并期待与更多开发者携手共创美好未来。
