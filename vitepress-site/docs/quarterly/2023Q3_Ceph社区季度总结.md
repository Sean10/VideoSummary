# Ceph 社区 2023 年第三季度总结报告

## 1. 本季度 Ceph 社区的主要活动和重点议题

### 1.1 病理学（Pathology）项目的改进与实施
- Devansh，Google Summer of Code 实习生，SEF 项目成员，介绍了病理学项目的改进和实施情况。
- 项目旨在改进病理学测试框架，使其更易于使用，并通过仪表板提供更直观的测试体验。
- 下一代 Pulpito 的开发，实现 GitHub 认证、作业调度和作业终止功能。

### 1.2 Ceph RGW 重构会议
- 会议主要讨论了 Ceph RGW 的重构计划，包括 Reef 版本更新、异步请求重构、线程池优化以及从 librados 迁移到 Neo-rados 的计划。
- 决定解决版本化对象一致性和加密对象损坏问题，以避免功能退化。
- 讨论了异步请求的正确性和防止新增阻塞调用。
- 计划降低线程池大小，并进行性能测试以确定最佳大小。
- 逐步从 librados 迁移到 Neo-rados。

### 1.3 Ceph 开发者会议：CDS Squid: RADOS
- 会议讨论了 Ceph MGR 的相关议题，包括性能问题、编码解码的可测试性、客户端之间的 QoS、读取均衡器、可用性跟踪、Erasure 编码配置文件的简化等。
- 将继续推进 Op Tracker 在 MGR 中的集成工作。
- 改进编码解码框架的测试覆盖率，并强制注册新的可编码类。
- 继续开发客户端之间的 QoS 功能，并解决相关的技术挑战。
- 开发自动运行的读取均衡器，并探索不同的触发机制。

## 2. 技术发展和创新亮点

### 2.1 Ceph Blue Store 会议
- 讨论了 Ceph Blue Store 的多个关键议题，包括分配器模拟器、碎片化处理、弹性共享 Blob、Codel 算法、自定义写前锁等。
- 将继续推进分配器模拟器的开发，并完善其度量标准。
- 在 Blue Store 中实现碎片整理的基本原语。
- 弹性共享 Blob 特性将继续在不同版本中进行测试和部署。
- 完善 Codel 算法和自定义写前锁的实现。

### 2.2 Ceph Code Walkthroughs: SeaStore
- SeaStore 是一个新的对象存储实现，专为 Crimson 的线程和回调模型设计。
- 目标是避免 CPU 密集型的元数据设计，如 roxdb，并提供灵活的架构以支持多种存储配置和工作负载。
- SeaStore 将支持多种存储配置，包括 QLC 或 ZNS 闪存设备、硬盘以及高性能的 NVMe 设备。
