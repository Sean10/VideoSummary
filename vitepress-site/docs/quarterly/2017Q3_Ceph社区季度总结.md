# 2017年第三季度Ceph社区季度总结报告

## 1. 本季度Ceph社区的主要活动和重点议题

本季度，Ceph社区重点关注了存储集群的优化和性能提升，主要议题包括：

- **跨数据中心复制与保证复制正确性**： 讨论了在不同数据中心间实现复制时维护全局顺序的挑战，并提出了相应的同步机制。
- **共享RBD客户端缓存**： 讨论了共享缓存的设计，包括使用共享内存和IPC机制，以及处理虚拟机迁移和故障。
- **统一PG日志修剪**： 讨论了优化PG日志管理的方法，使用时间戳和全局LRU来修剪日志。
- **去重和删除快照**： 讨论了在Ceph存储集群中实现数据去重的方法，以及优化删除快照性能。
- **统一QoS**： 讨论了在Ceph存储集群中实现统一QoS的方法，使用QoS策略和QoS表进行控制。
- **M Clock优化**： 讨论了优化M Clock性能的方法，使用分片和线程池提高性能。

## 2. 技术发展和创新亮点

本季度，Ceph社区在以下方面取得了显著的技术进步和创新：

- 提出了时间切片和定时器来同步客户端操作的跨数据中心复制方案。
- 实现了基于原始操作日志和快照的复制正确性保证方法。
- 设计了使用共享内存和IPC机制的RBD客户端缓存共享方案。
- 提出了基于时间戳和全局LRU的PG日志修剪优化方法。
- 推进了数据去重和删除快照功能的实现。

## 3. 重要的决策和里程碑

本季度，Ceph社区做出了以下重要决策和里程碑：

- Ceph Luminous版本发布准备就绪，预计进行了最后的bug修复工作。
- 介绍了Ceph的新Web仪表板、服务映射、应用程序标签、日志改进、状态模块、配置选项、平衡器模块、自动调整P基因组、速率限制、快速失败请求、跨集群复制、共享读取缓存、阵列代码和Prometheus集成等功能。

## 4. 社区贡献和合作情况

本季度，Ceph社区成员在以下方面做出了贡献和合作：

- 参与了多个技术讨论，如跨数据中心复制、复制正确性保证、RBD客户端缓存等。
- 提出了针对Ceph功能更新和改进的建议。
- 共同修复了Ceph Luminous版本的bug。
- 积极参与Ceph与其他技术的集成开发。

## 5. 下一季度展望和计划

下一季度，Ceph社区将重点关注以下任务：

- 完成Ceph Luminous版本的发布。
- 持续优化跨数据中心复制、复制正确性保证、RBD客户端缓存等功能。
- 推进统一QoS、M Clock优化等新功能的开发。
- 加强社区贡献和合作，推动Ceph技术的持续发展。

本季度，Ceph社区取得了丰硕的成果，为Ceph技术的进一步发展奠定了坚实基础。在下一季度，社区将继续努力，为用户提供更加高效、可靠的存储解决方案。
