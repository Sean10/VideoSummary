### 会议纪要

**会议主题**： Ceph虚拟集群性能测试与优化

**参会人员**： Dan Garcia（主持人）及其他团队成员

**会议内容**：

**一、项目展示**

1. **3D交互式服务器室界面**： Dan展示了一个使用Blender软件制作的3D交互式服务器室界面，其中地板和通风口等细节与实际服务器室一致。
2. **Aterna CD 10000机架介绍**： 该机架由四个节点组成，包括一个管理节点和三个交换机，用于公共集群和管理节点网络。

**二、Ceph性能测试**

1. **OSD状态管理**： 当OSD处于非“up”状态时，相关磁盘将被移除，并在必要时重新启动。
2. **CPU亲和性调整**： 使用Linux Red Hat的CPU亲和性工具调整系统设置，并通过CPM工具调整CPU亲和性，以模拟大量瓶颈。
3. **性能测试**： 使用Rattle基准测试进行性能测试，包括吞吐量性能和延迟性能。
4. **网络瓶颈模拟**： 在虚拟环境中模拟网络瓶颈，如数据丢失和延迟，以测试集群网络的性能。

**三、测试结果分析**

1. **延迟对读取性能的影响**： 在添加1毫秒延迟后，读取性能从15MB/s降至60MB/s。
2. **数据包丢失对读取性能的影响**： 在公共网络中添加10%的数据包丢失会导致读取性能大幅下降。
3. **CPU亲和性对带宽的影响**： 将所有OSD分配到一个逻辑CPU核心会导致带宽下降，但将OSD线程分配到逻辑CPU可以优化性能。
4. **特定线程行为**： 通过调整CPU亲和性，可以观察特定线程的行为，从而优化性能。

**四、后续行动计划**

1. 继续进行性能测试，验证不同配置对性能的影响。
2. 优化Ceph集群配置，提高性能和稳定性。
3. 撰写测试报告，总结测试结果和优化建议。

**五、会议总结**

本次会议介绍了使用Blender和Python创建的Ceph虚拟集群的性能测试与优化方法，并通过实际测试结果验证了不同配置对性能的影响。下一步将继续优化Ceph集群配置，以提高性能和稳定性。
