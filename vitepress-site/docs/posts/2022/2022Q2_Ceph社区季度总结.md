# Ceph 社区季度进展报告 · 2022 Q2

## 1. 本季度重点议题

本季度围绕 **Reef 版本规划**展开了大量讨论，多个子系统同步推进，以下方向反复出现：

**Crimson/SeaStore 成熟化**
Crimson OSD 和 C-Store（SeaStore）是本季度最高频的议题。从 [CDS Reef - Crimson](/VideoSummary/2022/04/22/CDS_Reef_-_Crimson/) 的规划会议到每周例会，团队持续推进 GC 策略、ZNS 设备支持、多核快照等核心能力，并讨论了如何在 Reef 版本中达到可用状态。

**性能优化：AVL 分配器与 Snap Mapper**
AVL 分配器的搜索策略调整（近似匹配 vs 最佳匹配、基于时间的阈值）贯穿整个季度的性能会议。Snap Mapper 的全局锁竞争问题在 6 月多次被讨论，成为 RBD 镜像性能的关键瓶颈。

**RGW Zipper 架构重构**
[CDS Reef - Rados Gateway](/VideoSummary/2022/04/14/CDS_Reef_-_Rados_Gateway/) 中提出的 Zipper 项目（动态加载存储后端、独立模式、过滤层）是 RGW 本季度最重要的架构方向。

**Orchestrator 与部署体验**
Cephadm 二进制重构、NFS/Ganesha 多实例支持、断开环境部署等问题在 Orchestrator 系列会议中持续讨论，反映出生产部署场景的复杂性正在驱动工具链演进。

**可观测性与遥测**
集中式日志（Loki/Promtail）、Prometheus 指标扩展、Jaeger 追踪集成在多个会议中被提及，可观测性成为本季度的横切关注点。

## 2. 技术亮点

### 2.1 Crimson / SeaStore

- **GC 策略改进**：[Ceph Crimson SeaStore Meeting 2022-06-22](/VideoSummary/2022/06/27/Ceph_Crimson_SeaStore_Meeting_2022-06-22/) 中，Ying Jin 报告了改进的代数 GC 策略，通过将相似年龄和特性的 extent 存储在同一 segment，显著减少了写放大和事务冲突。
- **ZNS 设备支持**：ZNS segment manager 已在真实设备上完成测试，讨论了 ZNS 设备关闭 segment 后不可重新打开的约束处理方案。
- **LBA 树简化**：C-Store 内部重写简化了 LBA 树结构，增加了非日志段存储扩展能力，并引入了基于可中断 future 的冲突检测机制。
- **多核快照与清理**：确定为 Reef 版本的重点，初步方案是在静态磁盘分区上运行多个 C-Store 实例。
- **性能瓶颈定位**：[Ceph Crimson SeaStore Meeting 2022-06-22](/VideoSummary/2022/06/27/Ceph_Crimson_SeaStore_Meeting_2022-06-22/) 中识别出 GC 过程中 cache 数据结构查找效率低下，决定优化 cache 结构。

### 2.2 BlueStore 与存储性能

- **AVL 分配器**：[Ceph Performance Meeting 2022-04-07](/VideoSummary/2022/04/07/Ceph_Performance_Meeting_2022-04-07/) 记录了 NVMe 节点 IOPS 从 70k-80k 下降至 20k-30k 的严重回归，根因定位到 AVL 分配器搜索策略变更。后续会议中提出基于时间阈值的搜索限制方案并持续验证。
- **Snap Mapper 重写**：[Ceph Performance Meeting 2022-06-23](/VideoSummary/2022/06/27/Ceph_Performance_Meeting_2022-06-23/) 中Gaby 提出将 Snap Mapper 从 RocksDB 迁移到内存数据结构（Red-Black 树改为哈希表），并按 PG 拆分以消除全局锁竞争，这是本季度性能方向最重要的架构改进之一。
- **RocksDB 调优**：[Ceph Performance Meeting 2022-06-23](/VideoSummary/2022/06/27/Ceph_Performance_Meeting_2022-06-23/) 测试显示调整 Level 0/1 和使用更多小缓冲区可在不显著增加写放大的前提下提升 RBD 性能。[Ceph Performance Meeting 2022-06-30](/VideoSummary/2022/06/30/Ceph_Performance_Meeting_2022-06-30/) 讨论了现有 RocksDB 调优博客文章存在未经 QA 验证的风险，决定撰写新文章明确各参数的副作用。
- **PG 日志优化**：[CDS Reef - Performance](/VideoSummary/2022/04/14/CDS_Reef_-_Performance/) 中讨论了利用 RocksDB WAL 机制优化 PG 日志存储的原型方案。
- **BlueStore 零块检测**：[Ceph Developer Monthly 2022-06-01](/VideoSummary/2022/06/03/Ceph_Developer_Monthly_2022-06-01/) 讨论了零块检测在厚置备 RBD 镜像场景下的性能问题，提出引入逻辑范围与物理范围区分的改进方案。

### 2.3 RGW

- **Zipper 架构**：支持动态加载存储后端、独立运行模式（无需集群连接）、数据缓存过滤层，为外部项目集成提供基础。
- **S3 Select 扩展**：新增 JSON 格式对象查询支持，并探索与 AeroFlight/Flight SQL 的列式数据集成。
- **异步重构**：减少线程数量，提升并发性能。
- **HTTP/3 支持**：开始初步研究，计划在 RGW 中引入 QUIC 协议以降低延迟。
- **多站点改进**：动态重分片提升可扩展性，改进同步公平性；讨论用 Golang 重写多站点测试套件，并引入 MinIO Warp 进行工作负载测试。
- **可观测性**：集成 Jaeger 构建追踪原语，探索基于 Lua 的条件追踪。

### 2.4 RBD

[CDS Reef - RBD](/VideoSummary/2022/04/22/CDS_Reef_-_RBD/) 规划了以下 Reef 目标：
- 支持加密克隆（不同密码和加密格式）
- 改进持久性宽背缓存（pmem 模式）
- 开发 NVMe-oF 网关替代现有 iSCSI 网关
- 扩展镜像性能测试规模，支持更多并发镜像数量
- 改进 rbd-mirror 状态机文档，添加状态图

### 2.5 CephFS

[CephFS Code Walkthrough - Kernel Client Overview](/VideoSummary/2022/05/24/CephFS_Code_Walkthrough_-_Kernel_Client_Overview/) 进行了内核客户端代码深度解析，涵盖 VFS 驱动、超级块/iNode 结构、路径名解析、原子打开、netfs 新网络请求处理层等，为社区贡献者提供了重要的代码导读。

### 2.6 Dashboard

[CDS Reef - Dashboard](/VideoSummary/2022/04/22/CDS_Reef_-_Dashboard/) 规划了多项改进：
- 集中式日志系统（Loki + Promtail）
- 多集群监控与管理
- 后端分页和过滤以支持大规模集群
- 基于 JSON 的后端驱动 UI 表单生成

[Ceph User + Dev Monthly 2022-06-01](/VideoSummary/2022/06/01/Ceph_User_+_Dev_Monthly_2022-06-01/) 演示了 Dashboard 新增的 CephFS 卷组、子卷管理功能（创建、编辑、删除、快照）。

### 2.7 Orchestrator / Cephadm

- **Cephadm 二进制重构**：[Ceph Orchestrator Meeting 2022-05-04](/VideoSummary/2022/05/04/Ceph_Orchestrator_Meeting_2022-05-04/) 讨论了模块化重构进展，解决后向兼容性问题，并创建 etherpad 跟踪相关问题。
- **磁盘重扫描**：Paul 开发了基于 `gather facts` 的磁盘重扫描替代方案，加速外部存储设备的库存信息收集。
- **Prometheus 服务发现**：提出 PR 支持外部 Prometheus 实例通过服务发现端点自动发现 Ceph 监控目标。
- **NFS/Ganesha 多实例**：[Ceph Orchestrator Meeting 2022-06-21](/VideoSummary/2022/06/27/Ceph_Orchestrator_Meeting_2022-06-21/) 深入讨论了 GANESHA 集群故障转移（ZAPFIMO 方案）和 OpenStack 环境下稳定虚拟 IP 的需求。

### 2.8 插件系统

[Ceph Developer Monthly 2022-05-04](/VideoSummary/2022/06/03/Ceph_Developer_Monthly_2022-05-04/) 介绍了 IBM 为支持具备在线压缩功能的 NVMe 设备（22TB 逻辑块/9.6TB 物理空间）而开发的 `xblock_device` 插件系统，基于 erasure code 插件架构，并讨论了 Linux capability 安全模型的应用。

### 2.9 遥测

[Ceph Tech Talk - Telemetry Dashboard](/VideoSummary/2022/05/06/Ceph_Tech_Talk_-_Telemetry_Dashboard/) 和 [Ceph Orchestrator Meeting 2022-05-10](/VideoSummary/2022/05/24/Ceph_Orchestrator_Meeting_2022-05-10/) 详细介绍了遥测架构（Manager → Apache → PostgreSQL → Grafana）、多通道数据收集（基本/崩溃/设备/标识/性能）、隐私保护机制，以及遥测数据在发现软件缺陷、指导部署优化方面的实际价值。

## 4. 社区动态

### 4.1 CDS（Ceph Developer Summit）Reef 系列会议
本季度举办了大规模的 CDS Reef 规划会议，覆盖 Crimson、Dashboard、Governance、Orchestrator、Performance、RADOS、RBD、RGW 八个子系统，为 Reef 版本开发奠定方向基础。

### 4.2 定期例会活跃度
- **Crimson/SeaStore 周会**：每周持续举行，记录了 2022-05-11、2022-05-25、2022-06-07、2022-06-22 等多次会议，显示 Crimson 团队高强度的迭代节奏。
- **Performance 双周会**：覆盖 4 月至 6 月，持续跟踪 AVL 分配器、Snap Mapper、RocksDB 调优等议题。
- **Orchestrator 周会**：从 4 月到 6 月底持续举行，跟踪 Cephadm 重构、NFS 集成等工作。

### 4.3 用户与开发者月度会议
- [Ceph Developer Monthly 2022-03-02](/VideoSummary/2022/06/03/Ceph_Developer_Monthly_2022-03-02/)：集中式日志方案选型（Graylog vs Elasticsearch vs Loki）
- [Ceph Developer Monthly 2022-05-04](/VideoSummary/2022/06/03/Ceph_Developer_Monthly_2022-05-04/)：IBM NVMe 设备插件系统介绍
- [Ceph Developer Monthly 2022-06-01](/VideoSummary/2022/06/03/Ceph_Developer_Monthly_2022-06-01/)：BlueStore 零块检测语义讨论、Boost Accumulators 性能计数器改进
- [Ceph User + Dev Monthly 2022-06-01](/VideoSummary/2022/06/01/Ceph_User_+_Dev_Monthly_2022-06-01/)：PG Remapper 工具介绍、Dashboard CephFS 管理功能演示

### 4.4 科学工作组
[Ceph Science Working Group 2022-05-24](/VideoSummary/2022/05/26/Ceph_Science_Working_Group_2022-05-24/) 讨论了大型 HPC 集群（HP Apollos 硬件）的 scrubing 参数调优问题，提出基于 OSD 大小和工作负载自动调整默认 scrubing 参数的想法，并分享了 Cephalocon 参与计划。

### 4.5 技术讲座
[Ceph Tech Talk - Telemetry Dashboard](/VideoSummary/2022/05/06/Ceph_Tech_Talk_-_Telemetry_Dashboard/) 面向社区进行了遥测功能的完整介绍，展示了遥测数据在实际问题发现中的价值。

## 5. 下季度展望

基于本季度讨论内容，预计 2022 Q3 将重点推进以下方向：

**Crimson/SeaStore 继续成熟**
- 完成代数 GC 策略的完整实现和测试
- 推进多核快照和清理功能
- 改进调试子系统，使日志行为与 Classic OSD 一致
- 探索更频繁的快照发布（月度/周度自动构建）

**性能优化落地**
- Snap Mapper per-PG 内存化重构完成并合并
- AVL 分配器基于时间阈值的方案验证完毕后合并
- 发布经过 QA 验证的 RocksDB 调优指南
- 继续研究 OSD shard queue 空载时的线程唤醒效率问题

**RGW Zipper 推进**
- Zipper 过滤层和独立模式功能完善
- S3 Select JSON 支持和 AeroFlight 集成完成
- 异步重构减少线程数的工作收尾

**Orchestrator 稳定化**
- Cephadm 二进制重构完成
- NFS/Ganesha 故障转移方案（ZAPFIMO）验证
- OpenStack 环境下稳定虚拟 IP 方案落地
- 磁盘重扫描功能合并

**Dashboard 功能扩展**
- Loki 集中式日志系统集成
- 多集群监控初步实现
- CephFS 子卷快照管理功能完善

**治理与测试**
- 建立 Crimson 持续有效的门槛测试（pathological test）
- 改善发布说明编写流程
- 增加升级测试覆盖率，特别是 stretch 模式和大规模逻辑技能测试
