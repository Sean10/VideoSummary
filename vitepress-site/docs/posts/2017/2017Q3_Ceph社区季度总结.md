# Ceph 社区季度进展报告 — 2017 Q3

---

## 1. 本季度重点议题

本季度两次开发者月度会议围绕以下方向持续讨论：

- **Luminous 版本发布冲刺**：整个季度的核心工作是推动 Luminous 版本进入 GA 状态，bug 修复贯穿始终。
- **数据复制与一致性**：跨数据中心复制的全局顺序保证、OSD 故障时的复制正确性，是两次会议均涉及的核心难题。
- **性能与 QoS**：mClock 调度器优化、统一 QoS 策略、RBD 共享读取缓存等议题反复出现，体现了社区对 I/O 质量管控的持续投入。
- **存储效率**：数据去重（deduplication）和 PG 日志修剪（PG log trimming）作为降低存储开销的关键方向被重点讨论。

---

## 2. 技术亮点

### 管理与可观测性

在 [2017-AUG-02 开发者月度会议](/VideoSummary/2017/08/29/2017-AUG-02_-_-_Ceph_Developer_Monthly/) 中，多项面向运维的新能力被集中介绍：

- **新 Web 仪表板**：提供集群监控与管理的图形化界面，降低运维门槛。
- **服务映射（Service Map）**：支持从命令行或模块中查询集群内各服务的注册信息。
- **应用程序标签（Application Tags）**：允许对存储池打标签，便于区分业务用途。
- **配置系统改进**：新增 `help` 和 `diff` 子命令，提升配置可读性与变更追踪能力。
- **Prometheus 集成**：将 Ceph 指标暴露给 Prometheus，打通与主流监控生态的对接。
- **平衡器模块（Balancer Module）**：提供数据均衡操作的简化入口，支持自动调整 PG 分布。

### 数据路径与缓存

- **共享 RBD 客户端缓存**：在 [2017-SEP-06 开发者月度会议](/VideoSummary/2017/09/12/2017-SEP-06_-_-_Ceph_Developer_Monthly/) 中提出基于共享内存与 IPC 机制的缓存共享方案，目标是减少同主机多客户端场景下的重复 I/O。
- **速率限制（Rate Limiting）**：支持对特定账户限制 I/O 操作速率，为多租户场景提供基础隔离能力。
- **快速失败请求（Fast Fail）**：引入请求快速失败机制，减少异常路径下的等待延迟。

### 存储效率

- **数据去重（Deduplication）**：提出使用对象映射与内容地址存储池（content-addressed pool）实现块级去重，详见 [2017-SEP-06 开发者月度会议](/VideoSummary/2017/09/12/2017-SEP-06_-_-_Ceph_Developer_Monthly/)。
- **统一 PG 日志修剪**：提出基于时间戳与全局 LRU 的 PG log修剪策略，控制日志膨胀。
- **快照删除优化**：通过从 OSD map 中提前移除已删除快照信息，加速快照清理流程。

### 复制与一致性

- **跨数据中心复制**：提出时间切片（time slicing）与定时器机制来同步跨 DC 的客户端操作顺序，应对全局顺序维护的挑战。
- **复制正确性保障**：提出利用原始操作日志（raw operation log）与快照（snapshot）组合的方式，在 OSD 故障场景下保证对象状态正确性。

### QoS 与调度

- **统一 QoS**：讨论了基于 QoS 策略表的统一控制框架，目标是跨 RBD、CephFS、RGW 提供一致的 I/O 优先级管理。
- **mClock 优化**：提出通过分片（sharding）与线程池改进 mClock 调度器的吞吐与延迟表现。

---

## 3. 重要决策与里程碑

- **Luminous 版本即将 GA**：在 [2017-AUG-02 开发者月度会议](/VideoSummary/2017/08/29/2017-AUG-02_-_-_Ceph_Developer_Monthly/) 中，Leo 明确表示 Luminous 处于最终 bug 修复阶段，这是本季度最重要的里程碑节点。Luminous 是 Ceph 首个正式包含 BlueStore 作为默认后端、并引入 MGR 框架的长期支持版本。
- **MGR 模块生态初步成型**：平衡器模块、状态模块、Prometheus 插件等均以 MGR 模块形式交付，标志着 MGR 插件化架构在本季度开始落地。
- **跨集群复制方向确立**：跨数据中心复制被列为后续重点开发方向，相关设计讨论已在本季度展开。

---

## 4. 社区动态

- **开发者月度会议（CDM）持续举行**：本季度记录了 8 月和 9 月两次 Ceph Developer Monthly 会议，参与者涵盖核心开发者与社区贡献者，议题覆盖从版本发布到前沿特性设计的完整范围。
- **Kubernetes 集成关注度上升**：在 [2017-AUG-02 开发者月度会议](2017-AUG-02_-_Ceph_Developer_Monthly) 中提及 Ceph 与 Kubernetes 的集成，反映出社区对云原生场景的关注开始增强。
- **本季度暂无相关记录**：本季度材料中未出现具体的 Cephalocon 或线下 Summit 活动记录，亦无新贡献者统计数据。

---

## 5. 下季度展望

基于本季度讨论内容，预计 2017 Q4 将重点推进以下方向：

1. **Luminous 正式发布后的稳定化工作**：GA 后的 bug 修复、文档完善与用户反馈处理将是近期主线。
2. **跨数据中心复制落地**：本季度完成了设计讨论，下季度有望进入原型实现阶段。
3. **去重功能推进**：内容地址存储池方案已有初步设计，预计进入编码阶段。
4. **mClock 与统一 QoS 集成**：两者均处于设计收敛阶段，下季度可能合并为统一的 I/O 调度框架推进。
5. **MGR 模块持续扩展**：随着 Luminous 发布，社区贡献者有望围绕 MGR 框架开发更多监控、管理类插件。
6. **云原生方向深化**：Kubernetes 与 Prometheus 集成已在本季度提及，预计下季度会有更具体的 CSI 或 Rook 相关讨论出现。
