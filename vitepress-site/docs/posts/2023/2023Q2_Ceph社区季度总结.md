# Ceph 社区季度进展报告 · 2023 Q2

---

## 1. 本季度重点议题

本季度反复出现或重点讨论的技术方向集中在以下几个领域：

**性能与新一代 OSD 架构**
Crimson/SeaStore 项目是本季度最活跃的技术议题，多次专项会议持续推进。详见 [Crimson Project Update - Samuel Just IBM](/VideoSummary/2023/05/05/Crimson_Project_Update_-_Samuel_Just_IBM/) 和系列周会记录 [Ceph Crimson SeaStar-OSD 2023-04-12 Meeting](/VideoSummary/2023/04/12/Ceph_Crimson_SeaStar-OSD_2023-04-12_Meeting/)。

**RGW 多站点与对象存储**
RGW Refactoring 会议贯穿整个季度，重点围绕多站点复制的可靠性、Kafka 通知机制、Bucket Notifications 元数据同步等问题展开。详见 [Ceph RGW Refactoring Meeting 2023-04-26](/VideoSummary/2023/05/03/Ceph_RGW_Refactoring_Meeting_2023-04-26/)、[Ceph RGW Refactoring Meeting 2023-05-31](/VideoSummary/2023/05/31/Ceph_RGW_Refactoring_Meeting_2023-05-31/)。

**Reef 版本发布准备**
Reef 版本的 RC 切割和多站点测试是本季度末的核心工作，详见 [Ceph RGW Refactoring Meeting 2023-05-24](/VideoSummary/2023/05/24/Ceph_RGW_Refactoring_Meeting_2023-05-24/)。

**可观测性与 Telemetry**
Crash Telemetry、分布式追踪（OpenTelemetry/Jaeger）、消息驱动遥测系统等多个方向同步推进，详见 [Ceph Crash Telemetry - Observability in Action](/VideoSummary/2023/05/05/Ceph_Crash_Telemetry_-_Observability_in_Action_-_Yaarit_Hatuka_IBM/) 和 [Enhancing Observability in Rook Ceph](/VideoSummary/2023/05/05/Enhancing_Observability_in_Rook_Ceph_-_Deepika_Upadhyay_Gaurav_Sitlani_Koor_Technologies_Inc./)。

**Kubernetes 原生存储（Rook/CSI）**
Rook 的生产最佳实践、故障排除工具、动态多集群管理等议题在本季度多次出现，详见 [Best Practices of Production-Grade Rook Ceph Cluster](/VideoSummary/2023/05/05/Best_Practices_of_Production-Grade_Rook_Ceph_Cluster_-_Satoru_Takeuchi_Cybozu/) 和 [Critical Troubleshooting Tools for Rook Clusters](Critical_Troubleshooting_Tools_for_Rook_Clusters_-_Subham_KumarRai_Parth_Arora_IBM)。

## 2. 技术亮点

### BlueStore V2 演进
Adam Kupczyk 和 Mark Nelson 在 [BlueStore V2 - an Evolutionary Step Forward](/VideoSummary/2023/05/05/BlueStore_V2_-_an_Evolutionary_Step_Forward_-_Adam_Kupczyk_IBM_Mark_Nelson_Clyso_GmbH/) 中详细介绍了 BlueStore V2 的维护方向，包括引用计数机制优化、内存管理改进、碎片化问题处理，以及通过模拟器验证新分配策略的方法。懒惰压缩（lazy compression）和自定义写前锁（write-ahead lock）被列为潜在新特性。

### Crimson/SeaStore 多核支持与 Arch64 验证
Crimson 项目本季度完成了对 AArch64 平台的验证工作，华为团队在 [Ceph Crimson Verification on AArch64](/VideoSummary/2023/05/18/Ceph_Crimson_Verification_on_AArch64_-_Rixin_Luo_Huawei/) 中报告了禁用 LSE 指令后小包性能提升约 50%、大包提升约 8% 的测试结果。C-store 的内存泄漏问题被识别并计划贡献给社区。

### NVMe-oF Gateway 进入 Reef
[Ceph Days NYC 2023 - NVMe-overFabrics support for Ceph](/VideoSummary/2023/05/17/Ceph_Days_NYC_2023_-_NVMe-over-Fabrics_support_for_Ceph/) 报告了 NVMe over Fabrics Gateway 的实现进展：控制路径使用 gRPC，数据路径采用 SPDK，实验室测试性能已达原生性能的 92%，计划在 Reef 版本中发布初始版本。

### RGW Lua 脚本与存储类优化
[Ceph Tech Talk - RGW Lua Scripting Code Walkthrough](/VideoSummary/2023/05/24/Ceph_Tech_Talk_-_RGW_Lua_Scripting_Code_Walkthrough/) 详细介绍了 Lua 脚本在 RGW 中的钩子机制和执行细节。[Ceph Days NYC - Optimizing RGW Object Storage Mixed Media through Storage Classes and Lua Scripting](/VideoSummary/2023/05/17/Ceph_Days_NYC_-_Optimizing_RGW_Object_Storage_Mixed_Media_through_Storage_Classes_and_Lua_Scripting/) 展示了通过 Lua 脚本动态调整存储类别、结合 HDD/SSD/QLC SD 混合介质降低 TCO 的实践方案。

### mClock QoS 优化
[Ceph QoS Refinements for Background Operations Using MClock](/VideoSummary/2023/05/05/Ceph_QoS_Refinements_for_Background_Operations_Using_MClock/) 介绍了 mClock 调度器相对于 WPQ 的优势：动态成本模型、更友好的内置配置文件，以及在恢复操作中显著更低的客户端延迟。

### UADK 硬件加速
华为团队在 [Best UADK Acceleration Practice on Ceph Storage](/VideoSummary/2023/05/05/Best_UADK_Acceleration_Practice_on_Ceph_Storage_-_Dai_Zhiwei_Huawei/) 中展示了 UADK（User Space Acceleration Development Kit）在 BlueStore 压缩和 RGW 加密场景下的应用，CPU 使用率显著降低，计划将 UADK 支持集成到 Ceph 主分支。

### RGW 字符串属性优化
[Ceph RGW Refactoring Meeting 2023-05-31](/VideoSummary/2023/05/31/Ceph_RGW_Refactoring_Meeting_2023-05-31/) 讨论了通过哈希将 S3 属性名称从长字符串转换为短整数的优化方案，以减少动态字符串分配和内存使用，决定在 OSD 层内部实现，不改变现有 librados API。

### 内存泄漏"年度 Bug" 修复
Radoslaw Zarzynski 在 [Bug of the Year - A Memory Leak Reboot Could Not Help with](/VideoSummary/2023/05/05/Bug_of_the_Year_-_A_Memory_Leak_Reboot_Could_Not_Help_with_-_Radoslaw_Zarzynski_IBM/) 中披露了一个自 2017 年存在于 OSD 中的内存泄漏问题，根源在于 `std::listsize()` 的非常数时间复杂度导致 PG lock 中dupes 结构膨胀，在 Octopus 版本因 auto-scaler 默认开启而加剧，本季度完成修复。

### TCMalloc/内核 madvise 校验和问题
Canonical 团队在 [Chasing Bad Checksums](/VideoSummary/2023/05/05/Chasing_Bad_Checksums_-_A_Journey_Through_Ceph_TCMalloc_and_the_Linux_Kernel_-_Dan_Hill_Canonical/) 中分享了一个跨越 Ceph、TCMalloc 和 Linux 内核的复杂 bug 排查过程：`madvise(MADV_FREE)` 导致页面被延迟释放，在高内存压力下引发 RocksDB 校验和错误崩溃。修复方案包括在 RocksDB 路径添加重试、修改 Gperftools 使用 `MADV_DONTNEED`，以及提交内核补丁。

### Ceph on Windows
[Ceph on Windows](/VideoSummary/2023/05/05/Ceph_on_Windows_-_Alessandro_Pilotti_Cloudbase_Solutions/) 展示了 Cloudbase Solutions 开发的 Windows 原生 Ceph 集成方案，包括新内核驱动 `wimbd.sys`，性能显著优于传统 iSCSI Gateway，支持 Windows Server 2016/2019/2022 及 Hyper-V 集群场景。

## 3. 重要决策与里程碑

**Reef 版本发布时间调整**
原计划 3 月发布的 Reef 版本因实验室故障推迟至 6 月，RC 版本切割计划在 2023-05-24 会议后的下周执行，详见 [Ceph Days NYC - State of the Cephalopod](/VideoSummary/2023/05/19/Ceph_Days_NYC_-_State_of_the_Cephalopod/) 和 [Ceph RGW Refactoring Meeting 2023-05-24](/VideoSummary/2023/05/24/Ceph_RGW_Refactoring_Meeting_2023-05-24/)。

**IBM 正式接管 Ceph 团队**
IBM 于 2023 年 1 月 1 日将 Red Hat Ceph 团队纳入存储部门，并承诺坚持开源优先战略，成为 Ceph 基金会 premium member，详见 [Ceph Days NYC 2023 - Ceph Crossing the Chasm](/VideoSummary/2023/05/17/Ceph_Days_NYC_2023_-_Ceph_Crossing_the_Chasm/)。

**社区治理模型变更**
Ceph 项目从单一领导模型转变为理事会（Council）模型，由各组件负责人选举产生，负责技术治理和社区管理，详见 [Ceph Days NYC - State of the Cephalopod](/VideoSummary/2023/05/19/Ceph_Days_NYC_-_State_of_the_Cephalopod/)。

**Cephadm 基于包的部署方案立项**
[Ceph Orchestrator 2023-05-02](/VideoSummary/2023/05/03/Ceph_Orchestrator_2023-05-02/) 会议决定启动基于包（package-based）的 Cephadm 开发，以满足不希望使用容器化部署的用户需求，计划进行概念验证。

**openEuler 引入 Upstream**
[Ceph Developer Monthly 2023-04-05](/VideoSummary/2023/04/07/Ceph_Developer_Monthly_2023-04-05/) 讨论并确认了将 openEuler 操作系统引入 Ceph upstream 的路径，openEuler 社区将提供硬件资源支持 CI 自动化构建。

**Reef 多站点测试通过**
Mark 完成了 4 亿对象的多站点同步负载测试，未发现回归问题，为 Reef RC 发布提供了关键质量保障，详见 [Ceph RGW Refactoring Meeting 2023-05-31](/VideoSummary/2023/05/31/Ceph_RGW_Refactoring_Meeting_2023-05-31/)。

## 4. 社区动态

**Ceph Days NYC 2023**
本季度最重要的社区活动，在 Bloomberg纽约办公室举行，涵盖 State of the Cephalopod、NVMe-oF、SQL on Ceph、Telemetry、数据安全、多站点灾难恢复等多个主题，详见 [Ceph Days NYC 2023 - Welcome and Community Update](/VideoSummary/2023/05/17/Ceph_Days_NYC_2023_-_Welcome_and_Community_Update/)。

**Bloomberg 的社区贡献**
Bloomberg 分享了其大规模 Ceph 集群（约 65PB，4 个数据中心）的多站点灾难恢复实践，以及基于 RabitMQ + Celery 的消息驱动遥测系统，并表示计划更积极地参与上游贡献，详见 [Ceph Multi-Site at Scale - Bloomberg's Disaster Recovery Journey](Ceph_Multi-Site_at_Scale_-_Bloombergs_Disaster_Recovery_Journey) 和 [Ceph Days NYC 2023 - Why We Built A Message-Driven Telemetry System At Scale Ceph Cluster](/VideoSummary/2023/05/17/Ceph_Days_NYC_2023_-_Why_We_Built_A_Message-Driven_Telemetry_System_At_Scale_Ceph_Cluster/)。

**CERN 十年经验分享**
CERN 分享了从 2013 年 300 TB 试点到当前 17 个集群、约 100 PB 存储容量的十年 Ceph 运营经验，详见 [Ceph Days NYC 2023 - Ceph at CERN - A Ten-Year Retrospective](/VideoSummary/2023/05/17/Ceph_Days_NYC_2023_-_Ceph_at_CERN_-_A_Ten-Year_Retrospective/)。

**新手用户体验改进讨论**
[A Welcoming Ceph Experience - Improvements for First-Time Users](A_Welcoming_Ceph_Experience_Improvements_for_First-Time_Users_or_-_How_to_MakeBeginers_Love_Ceph) 和 [Embracing Ceph](Embracing_Ceph_-_Key_FactorsDriving_Companies_to_Adopt_Ceph_Storage_Solutions) 两场讨论聚焦于降低 Ceph 入门门槛，社区成员呼吁改进文档、提供交互式入门引导、明确硬件建议。

**科学计算 BoF**
[Ceph in Scientific Computing and Large ClustersBoF](/VideoSummary/2023/05/05/Ceph_in_Scientific_Computing_and_Large_Clusters_BoF/) 建立了科学计算领域 Ceph 用户的定期交流机制，每两个月举行一次线上 Meetup。

**Telemetry 数据规模**
截至本季度，约 2500 个集群参与 Telemetry 上报，报告存储容量接近 1 Exabyte，详见 [Ceph Days NYC 2023 - Ceph Telemetry - Observability in Action](/VideoSummary/2023/05/17/Ceph_Days_NYC_2023_-_Ceph_Telemetry_-_Observability_in_Action/)。

## 5. 下季度展望

基于本季度的讨论和进展，预计 2023 Q3 将重点推进以下方向：

**Reef 正式发布**
Reef RC 已在季度末切割，正式版本预计在 Q3 初发布，将带来 mClock QoS、NVMe-oF Gateway 初始版本、RGW 多站点改进、Crimson 实验性支持等新特性。

**Crimson 多核支持完善**
多核消息路由、调度机制优化以及 scrub 功能实现是 Crimson 项目的下一阶段目标，详见 [Crimson Project Update](/VideoSummary/2023/05/05/Crimson_Project_Update_-_Samuel_Just_IBM/)。

**RGW 多站点测试与稳定化**
Reef 发布后，多站点功能的进一步测试、Bucket Notifications 元数据同步实现、以及数据同步公平性问题的修复将成为重点，Bloomberg 团队已承诺参与测试工作。

**Cephadm 基于包部署原型**
基于包的 Cephadm 概念验证工作将在 Q3 推进，为不使用容器的用户提供替代部署路径。

**BlueStore V2 碎片化与压缩优化**
模拟器驱动的分配策略验证和懒惰压缩特性开发将持续推进。

**UADK 主分支集成**
华为团队计划将 UADK 压缩和加密加速支持提交至 Ceph 主分支，预计在 Q3 提交相关 PR。

**新手体验与文档改进**
社区已形成共识，将在 Q3 推进入门文档重构和交互式引导工具的开发，降低 Ceph 的使用门槛。
