# Ceph 社区 2023Q4 季度进展报告

## 1. 本季度重点议题

本季度 Ceph 社区的讨论高度集中在以下几个技术方向：

**RGW 通知系统重构**
SNS 主题权限管理、多站点通知复制、Bucket Notification V2 的设计与迁移路径贯穿整个季度，是讨论频次最高的议题。详见 [Ceph RGW Refactoring Meeting 2023-09-06](/VideoSummary/2023/10/04/Ceph_RGW_Refactoring_Meeting_2023-09-06/)、[Ceph RGW Refactoring Meeting 2023-11-15](/VideoSummary/2023/11/20/Ceph_RGW_Refactoring_Meeting_2023-11-15/)、[Ceph RGW Refactoring Meeting 2023-12-13](/VideoSummary/2023/12/13/Ceph_RGW_Refactoring_Meeting_2023-12-13/)。

**RGW IAM 与账户体系设计**
账户所有权模型、配额管理、角色权限归属等 IAM 相关议题从 10 月持续讨论至 12 月，是本季度架构层面最重要的设计工作。详见 [Ceph RGW Refactoring Meeting 2023-10-25](/VideoSummary/2023/11/20/Ceph_RGW_Refactoring_Meeting_2023-10-25/)、[Ceph RGW Refactoring Meeting 2023-12-13](/VideoSummary/2023/12/13/Ceph_RGW_Refactoring_Meeting_2023-12-13/)。

**多站点数据同步可靠性**
数据日志竞态条件、生命周期与复制的交互问题、多站点测试稳定性，是本季度多站点方向的核心挑战。

**RADOS 层能力扩展**
审计日志持久化、去重机制改进两个 RFE 在 CDM 会议中被提出，代表了 RADOS 层的新需求方向。

---

## 2. 技术亮点

### RGW 通知系统

- **SNS 主题权限收紧**：明确将主题与创建者用户绑定，修复任意用户可管理他人主题的安全问题，并计划通过策略（Policy）机制管理跨用户访问。详见 [Ceph RGW Refactoring Meeting 2023-09-06](/VideoSummary/2023/10/04/Ceph_RGW_Refactoring_Meeting_2023-09-06/)。
- **持久通知性能优化**：评估了增加 Kafka 工作线程的方案，结论是瓶颈在写入队列侧而非消费侧，计划增加 Kafka 客户端统计指标以辅助诊断。详见 [Ceph RGW Refactoring Meeting 2023-09-20](/VideoSummary/2023/10/04/Ceph_RGW_Refactoring_Meeting_2023-09-20/)。
- **Bucket Notification V2 功能标志**：将功能标志从 "notification syncing" 重命名为 "notification V2"，确认为全局标志，并开始规划从旧数据模型的迁移路径。详见 [Ceph RGW Refactoring Meeting 2023-12-13](/VideoSummary/2023/12/13/Ceph_RGW_Refactoring_Meeting_2023-12-13/)。

### 多站点数据同步

- **数据日志替代方案**：Adam 提出用 omap 跟踪未同步的桶分片，替代现有数据日志机制，以解决无限增长和竞态条件问题。方案引入时间戳优先级排序，支持目标区域优先处理旧变更。详见 [Ceph RGW Refactoring Meeting 2023-10-18](/VideoSummary/2023/10/18/Ceph_RGW_Refactoring_Meeting_2023-10-18/)。
- **生命周期与多站点复制冲突**：确认 UTC 午夜触发的生命周期处理会导致大量删除操作堆积在日志中，使多站点复制看似暂停。决策方向是不记录生命周期删除操作，依赖本地删除，并引入 Rados QoS 控制速率。详见 [Ceph RGW Refactoring Meeting 2023-10-11](/VideoSummary/2023/10/11/Ceph_RGW_Refactoring_Meeting_2023-10-11/)。
- **多站点删除标记一致性**：确认版本控制桶中生命周期过期操作在多站点间产生不一致删除标记版本 ID 的问题，并列入后续修复计划。详见 [Ceph RGW Refactoring Meeting 2023-12-13](/VideoSummary/2023/12/13/Ceph_RGW_Refactoring_Meeting_2023-12-13/)。

### IAM 与账户体系

- **根账户所有权模型**：确立根账户（root account）作为唯一具有所有权概念的主体，OIDC Provider、策略、配额均在账户级别管理，而非用户级别。详见 [Ceph RGW Refactoring Meeting 2023-10-25](/VideoSummary/2023/11/20/Ceph_RGW_Refactoring_Meeting_2023-10-25/)。
- **角色归属账户**：明确角色应由账户拥有而非单个用户，并重新审视 admin caps 在权限模型中的使用方式。详见 [Ceph RGW Refactoring Meeting 2023-12-13](/VideoSummary/2023/12/13/Ceph_RGW_Refactoring_Meeting_2023-12-13/)。
- **动态重分片改进**：提出在重分片队列中添加时间戳以支持延迟执行，并考虑在桶创建 API 中暴露分片计数字段。详见 [Ceph RGW Refactoring Meeting 2023-11-15](/VideoSummary/2023/11/20/Ceph_RGW_Refactoring_Meeting_2023-11-15/)。

### 依赖库与基础设施

- **librdkafka 版本问题**：当前发行版中的 librdkafka 版本过旧，存在崩溃和 TLS 证书功能缺失问题。决定以子模块方式引入新版本并静态链接作为临时方案，同时向 CentOS 和 Ubuntu 提交 bug 报告请求更新。详见 [Ceph RGW Refactoring Meeting 2023-11-08](/VideoSummary/2023/11/20/Ceph_RGW_Refactoring_Meeting_2023-11-08/)。
- **Coverity 静态分析**：系统性使用 Coverity 扫描 RGW 代码，识别出空引用、内存泄漏、未初始化变量等问题，约 40% 为误报，讨论将其纳入 CI 流程。详见 [Ceph RGW Refactoring Meeting 2023-09-27](/VideoSummary/2023/10/04/Ceph_RGW_Refactoring_Meeting_2023-09-27/)。

### RADOS 层

- **审计日志持久化 RFE**：CephFS 团队提出在 RADOS 中持久化存储审计日志的需求，计划开发新的 Manager 模块，支持用户选择性保存、权限控制和保留策略配置。
- **去重机制改进**：现有去重实现对小数据块效率低下，提出将小块打包到大对象中的新机制，需进一步性能测试。详见 [Ceph Developer Monthly 2023-10-04](/VideoSummary/2023/10/04/Ceph_Developer_Monthly_2023-10-04/)。

### Lua 集成与认证

- **Lua API 重组**：讨论了 Lua 脚本与 HTTP 头信息暴露的问题，提出重新组织 Lua API 以提供更清晰、安全的访问方式。
- **LDAP 弃用计划**：提出在下一个主要版本中弃用 LDAP 独立认证机制，建议迁移至 STS（Security Token Service）。详见 [Ceph RGW Refactoring Meeting 2023-11-29](/VideoSummary/2023/11/29/Ceph_RGW_Refactoring_Meeting_2023-11-29/)。

## 4. 社区动态

**定期会议**
本季度 RGW Refactoring Meeting 保持每周一次的节奏，共记录 9 次会议（9 月至 12 月），覆盖通知、多站点、IAM、数据日志等多个子方向，参与者包括 Adam、Casey、Matt、Jane、Eric、Ali 等核心贡献者。

**Ceph Developer Monthly**
- 10 月 CDM 聚焦 RADOS 层新需求（审计日志、去重），体现了上层应用对存储层能力的新诉求。
- 12 月 CDM 讨论了 Manager 模块加载的竞态问题，涉及 Python 模块异步加载机制的改进。详见 [Ceph Developer Monthly 2023-12-06](/VideoSummary/2023/12/13/Ceph_Developer_Monthly_2023-12-06/)。

**Ceph User + Dev Monthly**
11 月的用户开发联合会议由 Zach Dober 主持，重点推进《Ceph 入门指南》文档工作，收集社区对文档内容的反馈，计划增加高层次架构图和"试驾文档"。这反映了社区对降低新用户门槛的持续投入。详见 [Ceph User + Dev Monthly 2023-11-16](/VideoSummary/2023/11/16/Ceph_User_+_Dev_Monthly_2023-11-16/)。

**感恩节影响**
11 月 22 日会议因感恩节假期部分成员缺席，Jane 的多站点重试 PR 讨论顺延至下周，体现了北美社区的节假日节奏。详见 [Ceph RGW Refactoring Meeting 2023-11-22](/VideoSummary/2023/11/28/Ceph_RGW_Refactoring_Meeting_2023-11-22/)。

## 5. 下季度展望

基于本季度讨论内容，预计 2024Q1 将重点推进以下方向：

1. **Bucket Notification V2 迁移路径落地**：功能标志已确认，迁移代码路径的实现和测试将是近期重点，需处理旧数据模型的兼容升级。

2. **RGW 账户体系 PR 推进**：用户账户 PR 已有详细待办列表，角色归属账户的权限模型已明确，预计进入实质性代码审查和测试阶段。

3. **数据日志替代方案实现**：omap 方案的 CLS 条目修改和 REST 接口完善已列入计划，需同步考虑向后兼容性。

4. **多站点测试稳定性改善**：本季度多次提及多站点测试不稳定，预计会有专项改进投入，包括测试基础设施优化。

5. **librdkafka 上游推进**：子模块方案为临时方案，需持续跟进 CentOS/Ubuntu 的版本更新，并评估是否长期保留子模块。

6. **LDAP 弃用文档与迁移指南**：弃用计划已启动，需在正式发版前完成迁移文档和 Tracker 跟踪。

7. **RADOS 审计模块原型**：审计日志 RFE 已获社区认可，预计进入 API 设计和原型开发阶段。
