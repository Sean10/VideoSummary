# Ceph 社区 2023Q1 季度进展报告

---

## 1. 本季度重点议题

本季度 Ceph 社区围绕以下几个核心方向持续深入讨论：

**Crimson/SeaStore 新存储引擎推进**
Crimson OSD 和 SeaStore 是本季度最活跃的技术方向。团队持续推进多核 messenger 实现、内存泄漏修复、SeaStore 克隆机制设计，以及热数据缓存（hot data cache）功能的架构讨论。详见 [Ceph Crimson/SeaStore Meeting 2023-01-11](/VideoSummary/2023/01/12/Ceph_Crimson_SeaStore_Meeting_2023-01-11/)、[Ceph Crimson/Seastore Meeting 2023-03-15](/VideoSummary/2023/03/15/Ceph_Crimson_Seastore_Meeting_2023-03-15/)。

**RGW 重构与多站点稳定化**
RGW 的异步化重构（C++20 协程、Zipper 接口）、多站点同步策略问题、IAM 账户功能实现是本季度 RGW 方向的三条主线。Reef 分支在本季度完成分叉，多站点同步的日志修剪（bi-log triming）问题被重点关注。

**BlueStore/RocksDB 性能优化**
性能会议持续跟踪 RocksDB 升级（7.8.3）、有界迭代器（bounded iterators）、删除范围操作优化、BlueFS 增量日志更新等多个 PR 的进展。写放大（write amplification）问题在本季度被多次提及。

**Orchestrator 运维能力增强**
证书管理统一化（Secret store方案）、主机维护模式增强、keepalived 虚拟 IP 高可用、会议平台从 Blue Jeans 迁移至 Jitsi 等运维相关议题贯穿本季度。

---

## 2. 技术亮点

### Crimson / SeaStore

- **多核 messenger**：讨论了 OSD 与 PG 共享管理器的请求分发策略，连接引用类型从普通指针改为共享外部共享类型（shared external shared type）的方案正在评估中。详见 [Ceph Crimson/SeaStore Meeting 2023-01-18](/VideoSummary/2023/01/19/Ceph_Crimson_SeaStore_Meeting_2023-01-18/)、[Ceph Crimson/SeaStore Meeting 2023-03-29](/VideoSummary/2023/03/29/Ceph_Crimson_SeaStore_Meeting_2023-03-29/)。
- **SeaStore 克隆机制**：讨论了快照修剪（snapshot trimming）和快照恢复（snapshot recovery）的设计，提出在对象数据处理程序中建立类链表结构管理克隆引用，而非在 onode 中处理，以降低复杂度。详见 [Ceph Crimson/Seastore Meeting 2023-03-15](/VideoSummary/2023/03/15/Ceph_Crimson_Seastore_Meeting_2023-03-15/)。
- **热数据缓存**：讨论了在 SeaStore 中实现热数据缓存的设计原则，建议缓存策略设计为可插拔（pluggable），首先实现读取时的数据提升（read-time promotion），驱逐策略独立考虑。详见 [Ceph Crimson/SeaStore Meeting 2023-03-08](/VideoSummary/2023/03/08/Ceph_Crimson_SeaStore_Meeting_2023-03-08/)。
- **协程迁移**：讨论了将 interuptable future 代码迁移到标准 C++ 协程（co-routine）的工作，两种风格可自由混合，迁移为可选项。详见 [Ceph Crimson/Seastore Meeting 2023-03-22](/VideoSummary/2023/03/22/Ceph_Crimson_Seastore_Meeting_2023-03-22/)。

### RGW

- **IAM 账户功能**：Casey 介绍了 AWS IAM REST API 的实现目标，账户功能与现有租户（tenant）机制兼容，支持用户和策略的分层管理。详见 [Ceph RGW Refactoring Meeting 2023-02-21](/VideoSummary/2023/02/21/Ceph_RGW_Refactoring_Meeting_2023-02-21/)。
- **S3 Select 功能**：允许客户端将 SQL 语句推送到存储层执行，支持与 Spark、Trino 等分析框架集成，JSON 格式支持在 Reef 代码冻结前完成合并。详见 [Ceph Developer Monthly 2023-02-01](/VideoSummary/2023/02/02/Ceph_Developer_Monthly_2023-02-01/)。
- **端到端追踪（E2E Tracing）**：讨论了在 RGW RADOS 对象类中传递追踪信息的方案，以覆盖读写路径。详见 [Ceph RGW Refactoring Meeting 2023-03-08](/VideoSummary/2023/03/09/Ceph_RGW_Refactoring_Meeting_2023-03-08/)。
- **复制状态头**：讨论了 `x-amz-replication-status` 的实现，提出基于 bi-log triming 判断对象复制状态（PENDING/COMPLETED/FAILED/REPLICA）的方案。详见 [Ceph RGW Refactoring Meeting 2023-02-21](/VideoSummary/2023/02/21/Ceph_RGW_Refactoring_Meeting_2023-02-21/)。
- **用户配额性能计数器**：讨论了在 Prometheus 中监控每用户配额使用情况，通过缓存机制处理频繁更新，并为前端计数器添加用户标签。详见 [Ceph RGW Refactoring Meeting 2023-03-29](/VideoSummary/2023/03/29/Ceph_RGW_Refactoring_Meeting_2023-03-29/)。

### BlueStore / RocksDB 性能

- **RocksDB 升级至 7.8.3**：新版本改进了 range delete 的memtable 迭代性能，已通过 Valgrind 测试（添加了大量抑制规则），计划在接下来数月内进行大规模测试。详见 [Ceph Performance Meeting 2023-03-02](/VideoSummary/2023/03/06/Ceph_Performance_Meeting_2023-03-02/)。
- **有界迭代器（Bounded Iterators）**：Igor 提交的 PR 通过限制 RocksDB 迭代范围解决无界迭代导致的性能下降问题，特别针对 ARM 范围键场景。详见 [Ceph Performance Meeting 2023-01-19](/VideoSummary/2023/01/20/Ceph_Performance_Meeting_2023--01-19/)。
- **BlueFS 增量日志更新**：减少对 RocksDB 的依赖，改善 BlueFS 日志写入性能，在生产环境中已观察到正面效果。详见 [Ceph Performance Meeting 2023-02-09](/VideoSummary/2023/02/14/Ceph_Performance_Meeting_2023-02-09/)。
- **写放大问题分析**：从 Nautilus 升级到 Pacific后观察到写操作平均大小增加，通过 perf dump 数据分析，怀疑与碎片化和元数据增加有关，尚未找到确切根因。详见 [Ceph Performance Meeting 2023-01-26](/VideoSummary/2023/01/31/Ceph_Performance_Meeting_2023-01-26/)。
- **Zero Back End**：Casey 介绍了用于优化 Beast 前端和 HTTP/3 前端性能的 Zero Back End 工具，团队讨论了其在 RGW 中的应用潜力。详见 [Ceph Performance Meeting 2023-03-16](/VideoSummary/2023/03/16/Ceph_Performance_Meeting_2023-03-16/)。

### Orchestrator

- **Secret store 统一证书管理**：提议引入类似 Kubernetes Secrets 的统一 Secret store，集中管理 RGW 前端证书、Grafana 证书、SSH 密钥等敏感数据，并监控证书到期状态。详见 [Ceph Orchestrator Meeting 2023-03-07](/VideoSummary/2023/03/07/Ceph_Orchestrator_2023-03-07/)。
- **keepalived 虚拟 IP 高可用**：讨论了通过 keepalived 为 Ceph Manager 提供稳定虚拟 IP，以支持外部 Prometheus 稳定抓取数据，需解决动态绑定和健康检查脚本问题。详见 [Ceph Orchestrator Meeting 2023-02-07](/VideoSummary/2023/02/08/Ceph_Orchestrator_Meeting_2023-02-07/)。
- **主机维护模式增强**：新增强制标志（"yes I really mean it"），允许在 PG 降级等情况下强制进入维护模式，并在文档中添加风险警告。详见 [Ceph Orchestrator Meeting 2023-02-21](/VideoSummary/2023/02/21/Ceph_Orchestrator_Meeting_2023-02-21/)。
- **OpenStack Manila 与 NFS 集成**：讨论了通过代理协议（proxy protocol）让 NFS Ganesha 获取实际客户端地址，从而支持客户端访问限制。详见 [Ceph Orchestrator Meeting 2023-03-14](/VideoSummary/2023/03/14/Ceph_Orchestrator_Meeting_2023-03-14/)。

## 3. 重要决策与里程碑

- **Reef 分支分叉**：Reef 发布分支在本季度完成分叉，所有后续改动需合并至 main 分支并通过 backport 流程。由于基础设施问题，Reef 版本发布推迟最多三个月。详见 [Ceph RGW Refactoring Meeting 2023-03-01](/VideoSummary/2023/03/06/Ceph_RGW_Refactoring_Meeting_2023-03-01/)、[Ceph RGW Refactoring Meeting 2023-01-18](/VideoSummary/2023/01/19/Ceph_RGW_Refactoring_Meeting_2023-01-18/)。
- **性能计数器 JSON 输出格式调整**：决定新增 `dump_counters` 命令，保持现有命令不变，逐步将计数器迁移到新命令，避免破坏性变更。详见 [Ceph Developer Monthly 2023-02-01](/VideoSummary/2023/02/02/Ceph_Developer_Monthly_2023-02-01/)。
- **OSD Flags 升级保护**：决定在升级前保存 OSD Flags 状态，升级后恢复，避免用户自定义设置被意外覆盖。详见 [Ceph Orchestrator Meeting 2023-03-14](/VideoSummary/2023/03/14/Ceph_Orchestrator_Meeting_2023-03-14/)。
- **多部分上传孤立对象检测**：针对多部分上传修复（已合并至 Reef），决定补充测试脚本，扫描 RADOS 对象和桶索引以检测泄露的孤立对象和索引条目。详见 [Ceph RGW Refactoring Meeting 2023-03-15](/VideoSummary/2023/03/15/Ceph_RGW_Refactoring_Meeting_2023-03-15/)。
- **基础设施迁移**：实验室从 Gluster 迁移工作持续进行，部分 VM 磁盘损坏导致 CentOS 8 构建和 Crimson 构建在季度初受阻。详见 [Ceph Crimson/SeaStore Meeting 2023-01-11](/VideoSummary/2023/01/12/Ceph_Crimson_SeaStore_Meeting_2023-01-11/)。

## 4. 社区动态

- **Cephalocon 2023 筹备**：Cephalocon 会议计划于四月举行，CFP（Call for Papers）截止日期在 2 月初，团队成员积极准备演讲提交。Science Working Group 决定在 Cephalocon 上举办 Birds of a Feather 面对面交流会，取代虚拟会议。详见 [Ceph Crimson/SeaStore Meeting 2023-02-08](/VideoSummary/2023/02/14/Ceph_Crimson_SeaStore_Meeting_2023-02-08/)、[Ceph Science Working Group 2023-01-31](/VideoSummary/2023/02/01/Ceph_Science_Working_Group_2023-01-31/)。
- **Science Working Group 活跃**：本季度首次 Science Working Group 会议汇聚了来自 Nebraska Lincoln大学、南非射电天文观测台（MeerKAT 望远镜数据存储）、CSC 等机构的用户，分享了 Ceph 集群升级（CentOS 7/8 → Rocky 8、Ubuntu 18.04 → 20.04）和 S3 认证管理的实践经验。详见 [Ceph Science Working Group 2023-01-31](/VideoSummary/2023/02/01/Ceph_Science_Working_Group_2023-01-31/)。
- **Google Summer of Code / Outreachy**：团队在 2月份的 RGW 会议中提醒成员提交与 Ceph 相关的项目想法，积极参与开源实习项目招募。详见 [Ceph RGW Refactoring Meeting 2023-02-08](/VideoSummary/2023/02/14/Ceph_RGW_Refactoring_Meeting_2023-02-08/)。
- **GitHub 两因素认证要求**：GitHub 组织即将强制要求 2FA，未启用的成员将被移除，团队提醒所有成员尽快配置。详见 [Ceph RGW Refactoring Meeting 2023-03-29](/VideoSummary/2023/03/29/Ceph_RGW_Refactoring_Meeting_2023-03-29/)。
- **会议平台迁移**：Blue Jeans 于 4 月 1 日关闭，社区各工作组在本季度末完成向 Jitsi 的迁移，录音功能需手动触发（不同于 Blue Jeans 的自动录音）。详见 [Ceph Orchestrator Meeting 2023-03-21](/VideoSummary/2023/03/21/Ceph_Orchestrator_Meeting_2023-03-21/)。
- **Coverity 静态分析**：RGW 团队讨论了使用 Coverity 进行静态代码分析，决定通过代码注释管理假阳性，由学生贡献者负责清理相关问题。详见 [Ceph RGW Refactoring Meeting 2023-01-22](/VideoSummary/2023/02/23/Ceph_RGW_Refactoring_Meeting_2023-01-22/)。

## 5. 下季度展望

基于本季度的讨论，预计 2023Q 将重点推进以下方向：

1. **Reef 版本发布**：Reef 分支已分叉，Q2 将进入密集的稳定化和 QA 测试阶段，重点验证多站点同步、RGW 重构功能和 BlueStore 性能改进。

2. **Crimson 多核 messenger落地**：多核 messenger 的 OSD/PG 共享管理器实现方案已基本确定，Q2 预计进入编码和测试阶段。

3. **SeaStore 克隆与快照完善**：克隆机制原型开发已启动，Q2 将推进快照修剪和恢复操作的完整实现，并参考 BlueStore 的交互设计。

4. **RGW IAM 账户功能代码审查与合并**：Casey 的 IAM 账户功能PR 已进入代码审查阶段，Q2 预计完成合并。

5. **RocksDB 7.8.3 大规模测试**：升级 PR 已合并，Q2 将进行数月的生产级测试，监控内存泄漏和性能回归。

6. **Orchestrator Secret store 实现**：统一证书管理方案已完成设计讨论，Q2 将进入实现和数据迁移阶段。

7. **Cephalocon 2023**：四月举行，预计带来大量社区交流和新特性展示，Science Working Group 的BoF 会议将促进科研用户与开发者的直接对话。
