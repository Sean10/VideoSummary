# Ceph 社区 2023Q3 季度进展报告

**报告周期：** 2023年7月 - 2023年9月  
**数据来源：** 21篇社区会议与技术分享总结

---

## 一、本季度重点议题

本季度 Ceph 社区围绕以下几个核心方向持续深入讨论：

**1. RGW 异步化与架构重构**  
RGW 的异步请求重构是本季度最高频的议题，贯穿多次重构会议。核心目标是消除所有阻塞的 librados 调用，并最终大幅缩减线程池规模。详见 [Ceph_RGW_Refactoring_Meeting_2023-06-28](/VideoSummary/2023/07/03/Ceph_RGW_Refactoring_Meeting_2023-06-28/) 和 [Ceph_RGW_Refactoring_Meeting_2023-06-07](/VideoSummary/2023/07/03/Ceph_RGW_Refactoring_Meeting_2023-06-07/)。

**2. BlueStore 性能优化**  
BlueStore 的碎片化处理、弹性共享 Blob（Elastic Shared Blobs）、Codel 算法以及自定义写前锁等多项优化方向在本季度集中讨论，详见 [CDS_Squid_-_BlueStore](/VideoSummary/2023/07/25/CDS_Squid_-_BlueStore/)。

**3. Squid 版本规划（CDS 峰会）**  
本季度举办了 Ceph Developer Summit（CDS）Squid 专题，覆盖 BlueStore、Cephadm、Dashboard、RADOS、BD、RGW、NVMe-oF Gateway、Telemetry、Documentation 等几乎所有子系统，为下一个主要版本确立了开发方向。

**4. NVMe-oF Gateway 高可用与可扩展性**  
NVMe-oF Gateway 的 HA 方案、多路径支持、故障转移机制在本季度首次进入系统性讨论阶段，详见 [CDS_Squid_-_NVMe-oF-Gateway](/VideoSummary/2023/07/25/CDS_Squid_-_NVMe-oF-Gateway/)。

**5. 可观测性与遥测增强**  
标记性能计数器（labeled perf counters）、Prometheus 集成、Telemetry 数据收集等可观测性方向在多个子系统中同步推进。

---

## 二、技术亮点

### BlueStore

- **弹性共享 Blob（Elastic Shared Blobs）**：已完成开发并回溯到 Quincy 和 Reef 版本，本季度进入测试阶段。该特性优化了克隆对象时的存储效率。
- **碎片整理原语**：提出在 BlueStore 中引入对象碎片整理的基本原语，通过空闲周期队列实现碎片整理，详见 [CDS_Squid_-_BlueStore](/VideoSummary/2023/07/25/CDS_Squid_-_BlueStore/)。
- **Codel 算法**：引入 Codel 算法平衡延迟与吞吐量，通过批处理事务提升性能。
- **分配器模拟器**：启动 GSoC 合作项目，开发分配器模拟器，用于预测分配器变更对已部署 OSD 的影响。

### RGW

- **异步重构里程碑**：合并了扩展异步处理路径的大型 PR，并计划引入回归测试防止新增阻塞调用，详见 [Ceph_RGW_Refactoring_Meeting_2023-06-28](/VideoSummary/2023/07/03/Ceph_RGW_Refactoring_Meeting_2023-06-28/)。
- **迁移至 Neo-rados**：发现从 librados 迁移到 Neo-rados 有显著性能提升，开始规划逐步迁移。
- **标记性能计数器**：Ali 提交了针对 RGW 前端操作（put/get/delete 等）的标记性能计数器 PR，支持按桶名或用户名过滤，并计划与 Prometheus 集成，详见 [RGW_Refactoring_Meeting_2023-08-16](/VideoSummary/2023/08/16/RGW_Refactoring_Meeting_2023-08-16/)。
- **持久化通知改进**：推通知 TTL、重试机制、CLS FIFO 迁移等改进，详见 [RGW_Refactoring_Meeting_2023-08-09](/VideoSummary/2023/08/15/RGW_Refactoring_Meeting_2023-08-09/)。
- **OLH 并发 Bug 修复**：Corey Snyder 更新了 OLH 修复 PR，解决并发问题和遗留索引条目问题，详见 [Ceph_RGW_Refactoring_Meeting_2023-06-14](/VideoSummary/2023/07/03/Ceph_RGW_Refactoring_Meeting_2023-06-14/)。
- **用户存储桶扩展**：讨论通过分片策略突破单个 RADOS 对象 omap 200,000 键上限，详见 [Ceph_RGW_Refactoring_Meeting_2023-07-05](/VideoSummary/2023/07/05/Ceph_RGW_Refactoring_Meeting_2023-07-05/)。

### RADOS

- **读取均衡器自动化**：讨论将读取均衡器集成到平衡器管理模块，减少人工干预，详见 [CDS_Squid_-_RADOS](/VideoSummary/2023/07/25/CDS_Squid_-_RADOS/)。
- **Erasure Coding简化**：提出为小型集群创建预定义 Erasure 编码配置文件，降低使用门槛。
- **MGR Op Tracker**：讨论在 MGR 中实现操作跟踪器，以监控和管理性能问题。
- **可用性跟踪**：提出基于 PG 状态的长期可用性跟踪方案。

### RBD

- **镜像数据一致性修复**：确认并规划修复克隆图像同步时的数据损坏问题、丢弃操作未同步问题，详见 [CDS_Squid_-_RBD](/VideoSummary/2023/07/25/CDS_Squid_-_RBD/)。
- **Windows 支持改进**：讨论 Windows NBD 驱动和守护进程的改进，支持持久保留和多路复用。
- **实时迁移扩展**：讨论支持从非 Ceph 源进行实时迁移。

### SeaStore / Crimson

- **SeaStore 架构深度解析**：举办代码走读（Code Walkthrough）会议，详细介绍 SeaStore 的 LBA B树、back ref B树、日志记录机制、缓存管理和设备层级管理等核心设计，详见 [Ceph_Code_Walkthroughs_-_SeaStore](/VideoSummary/2023/07/03/Ceph_Code_Walkthroughs_-_SeaStore/)。
- SeaStore 已集成到 Crimson 实验版本，未来六个月优先推进稳定性和性能优化。

### NVMe-oF Gateway

- 讨论通过 Gateway Groups 实现 RBD 卷的高可用访问，初步决定由用户通过 CLI 指定首选 Gateway，而非自动负载均衡，详见 [CDS_Squid_-_NVMe-oF-Gateway](/VideoSummary/2023/07/25/CDS_Squid_-_NVMe-oF-Gateway/)。

### Cephadm

- 规划 SMB 支持（基于 Samba）、NVMF 支持、升级历史记录功能，以及 FBM 二进制重构，详见 [CDS_Squid_-_Cephadm](/VideoSummary/2023/07/25/CDS_Squid_-_Cephadm/)。

### 测试基础设施

- **Teuthology 友好化**：GSoC 实习生 Devansh 开发了下一代 Pulpito 仪表板，集成 Teuthology API，支持通过 Web UI 直接调度和终止测试作业，无需 SSH 登录，详见 [Ceph_Tech_Talk_-_Making_Teuthology_Friendly](/VideoSummary/2023/08/16/Ceph_Tech_Talk_-_Making_Teuthology_Friendly/)。

## 三、重要决策与里程碑

**Reef 版本发布**  
本季度 Reef 版本正式发布，[RGW_Refactoring_Meeting_2023-08-09](/VideoSummary/2023/08/15/RGW_Refactoring_Meeting_2023-08-09/) 中明确提及发布完成，并计划发布博客文章介绍新功能。

**Squid 版本开发方向确立**  
通过 CDS Squid 系列专题会议，社区确立了 Squid 版本的核心开发方向，包括：
- BlueStore 碎片整理与分配器模拟器
- Cephadm 的 SMB 和 NVMF 支持
- RGW 异步化完成与线程池缩减
- NVMe-oF Gateway HA 方案落地
- Dashboard 集群升级管理功能

**Cephadm 采用 Python Black 格式化**  
[Ceph_Orchestrator_Meeting_2023-08-29](/VideoSummary/2023/08/30/Ceph_Orchestrator_Meeting_2023-08-29/) 决定采用 Python Black 作为 Cephadm 的统一代码格式化工具，并计划纳入 CI 流程。

**RGW resharding 一致性修复回溯**  
[Ceph_RGW_Refactoring_Meeting_2023-06-07](/VideoSummary/2023/07/03/Ceph_RGW_Refactoring_Meeting_2023-06-07/) 确认将 resharding 一致性 Bug 修复回溯到 Pacific 和 Quincy 版本。

**Elastic Shared Blobs 回溯**  
弹性共享 Blob 特性已回溯到 Quincy 和 Reef 版本，详见 [CDS_Squid_-_BlueStore](/VideoSummary/2023/07/25/CDS_Squid_-_BlueStore/)。

## 五、下季度展望

基于本季度讨论内容，预计 2023Q4 将重点推进以下方向：

1. **RGW 异步化收尾**：完成所有阻塞 librados 调用的消除，推进线程池规模缩减，并开始 Neo-rados 迁移工作。

2. **BlueStore 碎片整理落地**：将碎片整理基本原语从设计推进到实现，分配器模拟器进入可用状态。

3. **NVMe-oF Gateway HA 方案实现**：完成 Gateway Groups 的多路径配置、故障转移测试，并推进并发 gRPC 处理的设计讨论。

4. **Squid 版本功能开发提速**：Cephadm 的 SMB 支持、NVMF 支持、升级历史记录等功能进入开发阶段；Dashboard 集群升级管理功能完成测试。

5. **可观测性体系完善**：RGW 标记性能计数器与 Prometheus 完成大规模集成测试；Telemetry 集群内容分析工具开发启动。

6. **文档体系建设**：新手入门指南（Beginner's Guide）和 V-Start 文档规范化在 Squid 发布前完成，详见 [CDS_Squid_-_Documentation](/VideoSummary/2023/07/20/CDS_Squid_-_Documentation/)。

7. **SeaStore 稳定性优化**：Crimson 中的 SeaStore 进入稳定性和 RBD 随机读写性能优化阶段，详见 [Ceph_Code_Walkthroughs_-_SeaStore](/VideoSummary/2023/07/03/Ceph_Code_Walkthroughs_-_SeaStore/)。
