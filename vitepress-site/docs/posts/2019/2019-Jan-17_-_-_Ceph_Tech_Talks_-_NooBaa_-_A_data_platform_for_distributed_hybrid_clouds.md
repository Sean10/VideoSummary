NooBaa 是一个针对分布式混合云环境的开源数据平台，该平台旨在帮助企业在多云环境中实现数据管理和优化。在 2019 年 1 月 17 日的 Ceph Tech Talks 中，NooBaa 的研发人员详细介绍了该平台的功能、架构和未来发展方向。

**会议要点**：

* **NooBaa 平台介绍**： NooBaa 支持本地、多云环境，通过 API 或本地资源访问。它提供端点抽象，隐藏数据存储位置和性能差异，提供透明访问。平台支持 S3 和 Lambda API，提供丰富的数据管理功能，并确保数据安全。
* **数据管理功能**： NooBaa 支持数据放置、数据冗余、对象版本控制、触发器等功能，以提高数据可靠性和效率。
* **未来发展方向**： NooBaa 将开源其平台，并计划进行容器化、与 OpenShift 和 Seafarers 集成，并探索联邦应用场景。
* **社区参与**： NooBaa 团队鼓励社区成员参与平台的开发和讨论。

**讨论内容**：

* NooBaa 与 Ceph 网关的集成
* 数据迁移
* 多云管理
* 容器化
* Kubernetes 集成

**行动计划**：

* NooBaa 团队将开源平台，并期待社区贡献。
* NooBaa 团队将继续开发容器化、OpenShift 和 Seafarers 集成等功能。
* 社区成员将讨论 NooBaa 平台与 Ceph 网关的集成、数据迁移、多云管理等话题。
