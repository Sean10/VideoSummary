### 会议纪要

**会议主题**： Ceph 云学院课程更新及用户反馈征集

**会议时间**： [具体时间]

**参会人员**： [参会人员名单]

**会议内容**：

**一、会议背景**

Florian Haas 主讲，介绍了 Ceph 云学院（City Cloud Academy）的更新情况，特别是针对 Ceph 分布式存储基础课程（CC 212）的改进和新增内容。

**二、讨论的主要议题**

1. **传统培训模式局限性**： 面对面培训成本高、效率低、难以规模化。
2. **在线学习不足**： 缺乏互动性和实践性，不利于学习者掌握复杂技术。
3. **Ceph 云学院优势**： 基于 Open EDX 平台，提供沉浸式、互动性强的实验室环境，允许学习者交流，快速创新和开放。
4. **课程更新**： 
    - 更新至 Nautilus 版本
    - 使用 CephFS 卷而非 Ceph Disk
    - 涵盖更多 Ceph 技术细节，如 fuse、内核文件系统驱动等
    - 提供实用的仪表盘操作内容
    - 涵盖 Eurasia 代码库和配置文件
    - 更新至最新版本

**三、决定的事项**

1. Ceph 云学院将继续免费提供 CC 212 课程，每月开放 20 个免费名额。
2. 欢迎用户反馈课程内容，以便持续改进课程质量。

**四、后续行动计划**

1. Ceph 云学院团队将根据用户反馈，不断完善课程内容。
2. Ceph 云学院将积极推广课程，扩大用户群体。

**五、其他事项**

1. 用户可以通过访问 City Cloud Academy 网站查看课程详情。
2. 用户可以通过 Twitter 关注 Ceph 云学院，获取最新课程信息。

**会议总结**：

本次会议介绍了 Ceph 云学院的课程更新情况，并强调了用户反馈对课程改进的重要性。Ceph 云学院将继续致力于提供高质量、实用的 Ceph 技术培训，帮助用户更好地掌握 Ceph 技术。
