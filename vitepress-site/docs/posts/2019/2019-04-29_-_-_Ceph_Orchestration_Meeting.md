### 会议纪要

**会议时间**： 2023年4月29日

**会议主题**： Orchestrators 团队会议

**会议内容**：

**一、Rook 1.0.0 更新**

*   Rook 1.0.0 版本即将发布，代码层面已无阻塞问题。
*   新网站开发完成，将与 Rook 1.0.0 版本一同发布，带来新的视觉和用户体验。
*   确认 Rook 管理器配置路径需要包含管理器 ID 以确保配置的有效性。

**二、Ceph 与 Tautology 集成**

*   团队讨论了将 Ceph 与 Tautology 的集成，但遇到了 API 集成难度大等问题。
*   建议将测试分为两部分，在 Tautology 和 Cuban Edda 环境中进行。
*   需要解决 Docker 镜像构建和不同 Kubernetes 环境测试的问题。

**三、自动化测试**

*   团队强调了自动化测试的重要性，并分享了各自的环境和测试工具。
*   建议构建一个可由所有人使用的测试框架，并讨论了自动化构建 Docker 镜像的问题。

**四、其他事项**

*   讨论了 Ceph 的内存目标设置问题。
*   讨论了 Ceph 与其他存储提供商的集成。
*   讨论了即将举行的 Ceph 会议。

**五、行动计划**

*   审查新网站，确保其与 Rook 1.0.0 版本一同发布。
*   解决 Rook 管理器配置路径问题。
*   继续推进 Ceph 与 Tautology 的集成。
*   构建自动化测试框架。
*   解决 Docker 镜像构建问题。

**六、后续行动**

*   团队成员将根据行动计划继续推进工作。
*   团队将定期召开会议，讨论进度和问题。
