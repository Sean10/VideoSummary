**会议主题**： ZTE公司在Ceph社区的角色与贡献

**会议内容**：

1. **自我介绍**：
   - Luo Kexue介绍了自己，指出Mike的正确发音，并提及自己的英文名称为Science。

2. **ZTE公司介绍**：
   - ZTE公司成立于1985年，提供通信产品和服务，拥有超过80,000名员工，107个分支机构，19个研发中心遍布全球。
   - 公司产品包括移动设备、核心网络、5G无线、云计算和存储等。

3. **Ceph社区的参与**：
   - ZTE团队在OpenStack的实践中遇到可扩展性、功能和可靠性挑战，开始学习Ceph并修复文档中的错误和遗漏。
   - 通过贡献文档和报告问题，ZTE团队熟悉了Ceph社区的贡献流程，并修复了Ceph的bug，成为社区成员。
   - ZTE团队在Ceph社区贡献了bug修复、功能增强和性能优化，参与了Rados、BlueStore、RBDS、QoS、单一恢复映射等组件的改进。
   - 去年，ZTE加入了Ceph基金会，成为高级会员。

4. **Ceph社区的贡献**：
   - ZTE团队编写了两本关于Ceph的书籍，帮助中国开发者理解Ceph的BlueStore和RBD等组件。

5. **基于Ceph的分布式存储解决方案**：
   - ZTE团队基于Ceph构建了Club Storage，与开源Ceph兼容，并集成了缓存、智能网关等新组件，以优化性能和提供不同类型的存储服务。

6. **Club Storage的成功案例**：
   - Club Storage因其卓越的产品能力获得了全球客户的认可，包括中国三大运营商以及Wang welcome等。

7. **总结**：
   - Luo Kexue鼓励更多人加入Ceph社区，并享受这个过程。
   - 他认为硅谷应该是一个庆祝的地方，而不是测试或考试。
