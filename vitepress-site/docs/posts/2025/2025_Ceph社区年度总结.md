# Ceph 社区 2025 年度进展报告

## 一、全年技术演进

2025年是Ceph技术架构全面深化的一年。从材料来看，社区的技术重心集中在三条主线上：**新一代存储引擎的成熟**、**AI/云原生工作负载的适配**，以及**大规模运维自动化**。

### 1.1 从"可用"到"生产就绪"的跨越

Crimson/SeaStore 经过多年孵化，在2025年迈出了关键一步。详见 [Ceph_Developer_Summit_-_Crimson_SeaStore](/posts/2025/Ceph_Developer_Summit_-_Crimson_SeaStore))，Umbrella 版本规划中 Crimson 的目标已从"技术预览"转向"生产可用"：PG 分裂功能合并至 `main` 分支，SeaStore 作为默认后端存储首次通过 `cephadm` 完成部署测试，并开始定期发布性能基准数据。

### 1.2 AI 原生存储需求的涌现

多个演讲反映了 AI 工作负载对存储的新要求。[Architecting_Cloud_Storage_for_AI_Native_Applications-_Nathan_Goulding_Vultr](/posts/2025/Architecting_Cloud_Storage_for_AI_Native_Applications_-_Nathan_Goulding_Vultr)) 展示了 Vultr 部署超过 60PB Ceph 存储支撑 AMD MI300X GPU 集群，存储性能要求高达 50GB/s per GPU。RGW 路线图中也明确纳入了 S3 Vector API 和Lakehouse/Iceberg 集成，标志着 Ceph 正式将 AI/数据分析场景列为一等公民。

### 1.3 硬件演进驱动架构调整

NVMe 全闪存部署成为主流趋势。[A_Solid_case_for_NVMe._Jason_Buris_from_Sony](/posts/2025/A_Solid_case_for_NVMe._Jason_Burris_from_Sony)) 详细对比了 HDD 与 NVMe 的迁移路径，索尼互动娱乐已完成三代硬件演进，全面转向 NVMe。ZNS（分区命名空间）和 EDSS 格式等新兴硬件标准也进入社区视野。

## 二、重大里程碑

### 2.1 Squid 版本 GA

Squid 是2025年上半年的核心发布版本，主要亮点包括：

- **RGW Accounts（多租户增强）**：通过 AWS IAM 兼容接口实现租户资源自治，详见 [Ceph_Object_Storage_Roadmap_Session_atCephalocon_2025_-_Daniel_Parkes_Matthew_BenjaminIBM](/posts/2025/Ceph_Object_Storage_Roadmap_Session_at_Cephalocon_2025_-_Daniel_Parkes_Matthew_Benjamin_IBM))
- **S3 Bucket Logging**：终端用户可通过 S3 API 自行配置访问日志
- **混合云分层存储（Cloud Tiers）**：支持生命周期规则将数据自动迁移至 S3 Glacier 等云存储
- **NVMe-oF Gateway 技术预览**：为 Kubernetes 提供 NVMe over TCP 存储接口

### 2.2 Tentacle 版本发布

Tentacle 是2025年下半年的重要版本，多个演讲涉及其功能规划与发布状态：

- **NVMe-oF Gateway 生产就绪**：代码合并至 Ceph 主分支，详见 [Ceph_NVMe-of_Road_Map_-_Orit_Wasserman_Aviv_Caro_IBM](/posts/2025/Ceph_NVMe-of_Road_Map_-_Orit_Wasserman_Aviv_Caro_IBM))
- **CephFS Case Insensitive Subtree**：优化 Samba 在 CephFS 上的性能，详见 [A_Harbor-side_Chat_on_CephFS_-_Patrick_Donnelly_IBM](/posts/2025/A_Harbor-side_Chat_on_CephFS_-_Patrick_Donnelly_IBM))
- **RGW Notification V2**：企业级通知功能，支持多区域同步、权限模型和遥测，详见 [Ceph_Notification_at_Scale_-_Notification_V2_an_Enterprise-Level_Feature_-_Krunal_Chheda_Bloomberg](/posts/2025/Ceph_Notification_at_Scale_-_Notification_V2_an_Enterprise-Level_Feature_-_Krunal_Chheda_Bloomberg))
- **Dashboard Carbon设计系统**：全面现代化 UI 改造，详见 [Ceph_Developer_Summit_Dashboard](/posts/2025/Ceph_Developer_Summit_Dashboard))

### 2.3 Umbrella 版本规划启动

年底，社区启动了下一个版本 Umbrella 的规划，多个 Developer Summit 专题会议（BlueStore、CephFS、RGW、RADOS、Dashboard 等）集中讨论了各组件的路线图，详见 [Ceph_Developer_Summit_-_RADOS_CDS](/posts/2025/Ceph_Developer_Summit_-_RADOS_CDS))。

## 三、核心组件年度进展

### 3.1 RGW（RADOS Gateway）

RGW 是2025年功能迭代最活跃的组件之一。

**多租户与权限体系**：Squid 引入的 RGW Accounts 功能在 Tentacle 中进一步完善，新增 Customer Managed Policies、Account-wide Public Access Block 等 IAM 特性，向 AWS S3 兼容性又迈进一步。

**Bucket Snapshots**：[Ceph_RGW_Bucket_Snapshots_-_Beyond_Versioning_-_Yehuda_Sadeh_Weinraub_Ubiquiti](/posts/2025/Ceph_RGW_Bucket_Snapshots_-_Beyond_Versioning_-_Yehuda_Sadeh_Weinraub_Ubiquiti)) 详细介绍了超越 Object Versioning 的快照功能设计，通过引入 snapID 维度实现跨对象一致性备份，功能接近完成。

**通知系统 V2**：Bloomberg 主导推动的 Notification V2 已在生产环境启用，支持所有权模型、多区域同步、遥测指标和性能优化（队列写入从 S3 请求中解耦）。

**数据去重（DUP）**：Full DDUP PR 已提交测试，Small Object DDUP 逻辑开发中，并提供估算工具帮助用户评估去重收益。

**D4N 缓存**：下一代读写加速缓存，支持智能预取，性能优化代码预计纳入 Umbrella 版本。

**分布式限速**：Bloomberg 开源了基于 HAProxy 的 [An_Open_Source_Distributed_Rate-limiting_Service_for_Ceph-object_and_Other_HTTP_APIs-_Jacques_Heunis](/posts/2025/An_Open_Source_Distributed_Rate-limiting_Service_for_Ceph-object_and_Other_HTTP_APIs-_Jacques_Heunis))，支持 RPS、带宽和并发请求三维度限速。

### 3.2 CephFS

**Tentacle 新功能**：Case Insensitive Subtree 支持、File Block Diff API（优化备份效率）、MDS Journal Replay 进度监控、灾难恢复配置项增强。

**Umbrella 规划**：Per-Subvol Metrics（通过 Prometheus 监控每个子卷 IO 指标）、用户态 FScrypt 加密支持（兼容 Samba/NFS Ganesha），详见 [A_Harbor-side_Chat_on_CephFS_-_Patrick_Donnelly_IBM](/posts/2025/A_Harbor-side_Chat_on_CephFS_-_Patrick_Donnelly_IBM))。

**异步 IO 接口**：[Async_IO_with_Libcephfs_-_Dhairya_Parmar_IBM](/posts/2025/Async_I_O_with_Libcephfs_-_Dhairya_Parmar_IBM)) 介绍了为 NFS Ganesha 开发的 libcephfs 异步 IO 接口，显著降低线程争用，提升高并发场景吞吐量，未来计划集成至 Samba。

**FScrypt 用户空间加密**：[Bringing_fscrypt_Encryption_to_CephFS_Userspace_-_Christopher_Hoffman_IBM](/posts/2025/Bringing_fscrypt_Encryption_to_CephFS_Userspace_-_Christopher_Hoffman_IBM)) 展示了将内核 FScrypt 迁移至用户空间的进展，核心功能已完成，正在进行多客户端互操作性测试。

**审计日志**：[CephFS_Tell-Me-What-Happened_--Yes-I-Really-MeanIt_-_Anthony_D_Atri_IBM](CephFS_Tell-Me-What-Happened_--Yes-I-Really-Really-MeanIt_-_Anthony_D_Atri_IBM) 介绍了基于 SQLite/RADOS 的 CephFS 审计日志方案（`auditman`），预计随 Umbrella 版本发布。

### 3.3 BlueStore

BlueStore 在2025年进行了多项深度优化，详见 [BlueStore_Faster_+_Smaller_=_Better_-_Adam_Kupczyk_BM](/posts/2025/BlueStore_Faster_+_Smaller_=_Better_-_Adam_Kupczyk_BM)) 和 [Advancing_BlueStore_with_Real-World_Insights_-_Adam_Kupczyk_IBM](/posts/2025/Advancing_BlueStore_with_Real-World_Insights_-_Adam_Kupczyk_IBM))：

- **RocksDB WAL 格式重构**：合并 IO 操作，降低 10-15% 延迟
- **Onode 元数据重构**：采用 C++ polymorphic allocators，减少锁竞争
- **并行化崩溃恢复**：完全重写恢复机制，支持多线程，可达 60倍提速
- **真实工作负载分析**：开发 scraper 工具从 OSD 抓取历史操作数据，发现预取策略可减少 39% IO 操作
- **RocksDB 缓存优化**：修复大缓存元素导致的频繁驱逐问题（Umbrella 规划）

Developer Summit 专题会议（[Ceph_Developer_Summit_-_BlueStore_Part_1](/posts/2025/Ceph_Developer_Summit_-_BlueStore_Part_1))、[Ceph_Developer_Summit_-_BlueStore_Part_2](/posts/2025/Ceph_Developer_Summit_-_BlueStore_Part_2))）还讨论了 FIE Map 零值支持、PowerPC 大页支持、VM Provisioning 插件等方向。

### 3.4 Crimson/SeaStore

[Ceph_Developer_Summit_-_Crimson_SeaStore](/posts/2025/Ceph_Developer_Summit_-_Crimson_SeaStore)) 和 [56_Weeks_Later_-_Becoming_a_Jack_of_All_Trades](/posts/2025/56_Weeks_Later_-_Becoming_a_Jack_of_All_Trades)) 展示了 Crimson 的年度进展：

- PG 分裂功能合并至 `main`，PG 合并开发中
- SeaStore 作为 Crimson 默认后端，首次通过 `cephadm` 部署测试成功
- 随机读性能显著优于 Classic OSD，随机写仍在优化
- QoS/MClock 调度 PR 已提交，依赖项解决中
- 开始定期发布性能基准数据（IOPS、延迟等指标）
- ARM 架构 CI 增强，UADK 集成减少加密/压缩 CPU 占用，详见 [Arming_Ceph_-_CI_Enhancement_andUADK_Integration_-_Rongqi_SunHUAWEI_TECHNOLOGIES_CO._LTD.](/posts/2025/Arming_Ceph_-_CI_Enhancement_and_UADK_Integration_-_Rongqi_Sun_HUAWEI_TECHNOLOGIES_CO._LTD.))

### 3.5 NVMe-oF Gateway

NVMe-oF 是2025年新兴的重要组件，从技术预览走向生产就绪：

- Tentacle 版本代码合并至主分支，支持 Gateway Groups 和多路径高可用
- 故障转移时间优化目标：从 12 秒缩短至 5-7 秒（通过优化 beacon 机制）
- Active-Active 网关支持列入路线图
- Dashboard 集成完成，支持可视化管理
- CSI Driver 支持 Kubernetes NVMe-oF 存储接口

详见 [Ceph_Developer_Summit_-_NVMeoF_gateway](/posts/2025/Ceph_Developer_Summit_-_NVMe_oF_gateway)) 和 [Ceph_NVMe-of_Road_Map_-_Orit_Wasserman_Aviv_Caro_IBM](/posts/2025/Ceph_NVMe-of_Road_Map_-_Orit_Wasserman_Aviv_Caro_IBM))。

### 3.6 Dashboard

[Ceph_Developer_Summit_Dashboard](/posts/2025/Ceph_Developer_Summit_Dashboard)) 总结了 Dashboard 的年度进展：

- **Tentacle 亮点**：NVMe-oF Gateway Groups 管理、多集群支持（Multi-Cluster）、RGW Multi-Site 自动化向导、SMB 协议完整管理、Carbon Design System 引入
- **多集群管理**：[Ceph_Made_Easy_-_One_Dashboard_for_Multiple_Ceph_Clusters_-_Nizamudeen_A_IBMIndia_Private_Ltd](/posts/2025/Ceph_Made_Easy_-_One_Dashboard_for_Multiple_Ceph_Clusters_-_Nizamudeen_A_IBM_India_Private_Ltd)) 详细介绍了 Hub 集群架构和 Prometheus Federation 多集群监控方案
- **Umbrella 规划**：100% Carbon化、移除旧版 Dashboard（v2）、大规模集群（10,000+ OSD）性能优化、AI 辅助故障排查（实验性）

### 3.7 RADOS 核心

[Ceph_Developer_Summit_-_RADOS_CDS](/posts/2025/Ceph_Developer_Summit_-_RADOS_CDS)) 汇总了 RADOS 层的年度规划：

- **Fast EC 改进**：零检测功能、直接读取优化（小读取性能达副本池水平，大读取延迟降低 66%）、EC 配置迁移
- **Stretch 模式**：网络分区检测与 OSD 隔离、CRUSH 权重限制放宽
- **upmap 应用**：[Beyond_Balancing_-_HowUpmaps_Were_Used_To_Avoid_Disaster_-_Bryan_Stillwell_Akamai_Technologies](/posts/2025/Beyond_Balancing_-_How_Upmaps_Were_Used_To_Avoid_Disaster_-_Bryan_Stillwell_Akamai_Technologies)) 展示了 upmap 在硬件故障规避、集群扩容、存储后端迁移等场景的实战应用

## 五、下一年展望

基于2025年的讨论，2026年的技术路线和社区方向可以归纳为以下几点：

### 5.1 Umbrella 版本为核心交付目标

Umbrella 版本将是2026年的核心发布，预计包含：
- BlueStore 全面优化（RocksDB 缓存、Onode 重构、VM Provisioning 插件）
- CephFS 审计日志（`auditman`）正式发布
- RGW Bucket Snapshots GA、D4N 分布式缓存、S3 Vector API
- Dashboard 100% Carbon 化、旧版 Dashboard 退役
- Crimson/SeaStore 进一步稳定，EC Pool 支持

### 5.2 Crimson 走向生产

随着 PG 分裂/合并、SeaStore 集成、QoS 支持等功能逐步完善，Crimson 有望在 Umbrella 版本后进入更广泛的生产验证阶段。性能数据的定期发布将加速社区信心建立。

### 5.3 AI 与数据分析场景深化

S3 Vector API、Lakehouse/Iceberg 集成、高性能 NVMe 全闪存部署将成为吸引 AI 工作负载的核心竞争力。Vultr、DigitalOcean 等云服务商的实践将为社区提供规模化参考。

### 5.4 运维自动化与可观测性

大规模用户（DigitalOcean、Bloomberg、CERN）的运维实践表明，自动化工具链和可观测性是超大规模集群管理的关键。预计社区将在 `cephadm` 自动化、审计日志、Prometheus 指标覆盖等方面持续投入，详见 [Ceph_Developer_Summit_-_Cephadm](/posts/2025/Ceph_Developer_Summit_-_Cephadm))。

### 5.5 NVMe-oF 生态扩展

NVMe-oF Gateway 生产就绪后，Active-Active 多活架构、CSI Driver 完善、VMware vSphere 深度集成将是下一阶段重点，为 Kubernetes 和虚拟化平台提供高性能块存储替代方案。

### 5.6 数据持久性与安全性

[Ceph_Durability_-_How_Safe_Is_My_Data_-_Dan_van_derSter_CLYSO](/posts/2025/Ceph_Durability_-_How_Safe_Is_My_Data_-_Dan_van_der_Ster_CLYSO)) 开发的可靠性计算器将推动社区在 PG 配置、纠删码策略等方面建立更科学的最佳实践。FScrypt 用户空间加密、Subvolume Quarantine（隔离勒索软件）等安全特性也将在 Umbrella 版本中落地。
