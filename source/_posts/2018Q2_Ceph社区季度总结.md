# Ceph 社区 2018 Q2 季度进展报告

---

## 一、本季度重点议题

2018年第二季度，Ceph 社区围绕以下几个核心方向持续深入讨论：

**1. BlueStore 性能优化**
BlueStore 是本季度最高频的技术议题，涵盖缓存自动调优、内存分配器选型、位图分配器（Bitmap Allocator）设计、大页（huge pages）支持、PG 日志优化等多个子方向。详见 [2018-Jun-21_-_-Ceph_Performance_Weekly](2018-Jun-21_-_Ceph_Performance_Weekly) 和 [2018-May-17_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/05/17/2018-May-17_-_-_Ceph_Performance_Weekly/)。

**2. Mimic 版本冻结与 Nautilus 规划**
Mimic 版本在 4月底进入冻结状态，社区同步启动了 Nautilus 版本的特性规划，包括消息协议变更、Kerberos 集成、PG 合并与自动缩放等。详见 [2018-MAY-02_-_-_Ceph_Developer_Monthly](/VideoSummary/2018/05/03/2018-MAY-02_-_-_Ceph_Developer_Monthly/)。

**3. 易用性与集群管理改进**
Dashboard v2、REST API、健康状态报告改进、CLI 普通/专家模式分层等议题在开发者月度会议中反复出现。详见 [2018-APR-04_-_-_Ceph_Developer_Monthly](/VideoSummary/2018/04/05/2018-APR-04_-_-_Ceph_Developer_Monthly/)。

**4. 测试框架建设**
Teuthology（Teltale）测试框架的改进、OVH 测试环境搭建、RGW 功能测试自动化等是测试周会的持续议题。详见 [2018-Jun-13_-_-_Ceph_Testing_Weekly](/VideoSummary/2018/06/19/2018-Jun-13_-_-_Ceph_Testing_Weekly/) 和 [2018-Jun-20_-_-_Ceph_Testing_Weekly](2018-Jun-20_-_Ceph_Testing_Weekly)。

**5. Kubernetes/容器化存储**
Rook 项目和 Ceph 在 Kubernetes 上的集成为社区新热点，CSI 插件支持被列入路线图。详见 [2018-May-24_-_-_Ceph_Tech_Talks](/VideoSummary/2018/05/28/2018-May-24_-_-_Ceph_Tech_Talks/)。

## 二、技术亮点

### BlueStore 架构深度解析
社区举办了两场 BlueStore 源码走读（Code Walkthrough），系统讲解了 BlueFS、块设备接口、Bitmap Allocator、Onode/Blob 对象模型、事务处理流程、延迟 I/O（deferred I/O）等核心机制。详见 [2018-May-29_-_-_Ceph_Code_Walkthrough_-_BlueStore_part_1](/VideoSummary/2018/05/30/2018-May-29_-_-_Ceph_Code_Walkthrough_-_BlueStore_part_1/) 和 [2018-June-26_-_-_Ceph_Code_Walkthrough_-_BlueStore_part_2](/VideoSummary/2018/06/27/2018-June-26_-_-_Ceph_Code_Walkthrough_-_BlueStore_part_2/)。

**主要技术进展：**
- **Bitmap Allocator**：Igor 提交的新位图分配器在所有测试场景下均优于现有 B 树分配器，尤其在随机分配场景下优势显著，Sage 已审查并希望替换旧代码。详见 [2018-May-10_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/05/10/2018-May-10_-_-_Ceph_Performance_Weekly/)。
- **优先级缓存（Priority Cache）**：提交了 BlueStore 优先级缓存 PR，支持按数据缓存、元数据、RocksDB 键值缓存的优先级分配内存，并允许自动调优，解决了 BlueStore 与 RocksDB 缓存竞争导致性能下降的问题。详见 [2018-May-17_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/05/17/2018-May-17_-_-_Ceph_Performance_Weekly/)。
- **大页（Huge Pages）支持**：蓝鲸快照功能添加了大页支持，页面错误数量减少约三分之二。详见 [2018-Jun-14_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/06/18/2018-Jun-14_-_-_Ceph_Performance_Weekly/)。
- **内存分配器选型**：对比测试了 libc malloc、TC malloc、J malloc 等分配器，确认 TC malloc 或 J malloc 在性能和内存使用上更优，决定继续以其作为默认分配器。详见 [2018-Jun-28_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/06/28/2018-Jun-28_-_-_Ceph_Performance_Weekly/)。
- **Beast 替换 CivetWeb**：决定将 RGW 的 HTTP 前端从 CivetWeb 迁移至 Beast，以优化性能和资源消耗。详见 [2018-Apr-12_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/04/12/2018-Apr-12_-_-_Ceph_Performance_Weekly/)。
- **OpenSSL 加密加速**：Radice Slavs 提交的 OpenSSL 加密 PR 正在测试中，CJ 认为该改动很有前景。详见 [2018-Apr-26_-_-_Ceph_Performance_Weekly](/VideoSummary/2018/04/26/2018-Apr-26_-_-_Ceph_Performance_Weekly/)。

### RGW 功能进展
- 详细介绍了 RGW 的多地域复制、版本控制、生命周期管理、桶索引优化、异步 I/O 调度器等规划方向。详见 [Everything_YouWanted_to_Know_About_RadosGW_-_Orit_Wassermann_Matt_Benjamin](/VideoSummary/2018/04/23/Everything_You_Wanted_to_Know_About_RadosGW_-_Orit_Wassermann_Matt_Benjamin/)。
- 讨论了 RGW 对 AWS S3 接口的深度兼容性问题，计划完善测试套件并加强对 S3 接口变更的跟踪。详见 [RGW_S3_-_FeaturesVs_Deep_Compatibility_-_Robin_Johnson](/VideoSummary/2018/04/23/RGW_S3_-_Features_Vs_Deep_Compatibility_-_Robin_Johnson/)。

### CephFS 状态与路线图
- Luminous 版本已支持多活动 MDS、子树固定、目录碎片化、内存缓存限制、快照等特性。
- Mimic 版本计划新增内核配额支持、NFS 网关集成、缓存限制改进。详见 [Status_and_Future_of_the_Ceph_File_System_-_Patrick_Donnelly](/VideoSummary/2018/04/23/Status_and_Future_of_the_Ceph_File_System_-_Patrick_Donnelly/)。

### Dashboard v2 与管理 API
- 讨论了将 Open Atic 功能（NFS Ganesha 管理、iSCSI 目标管理）迁移至 Dashboard 的计划，引入角色和用户权限管理，计划在 Nautilus 版本正式推出 REST API。详见 [Ceph_Management_and_Monitoring_with_Dashboard_v2_-_Lenz_Grimer](/VideoSummary/2018/04/23/Ceph_Management_and_Monitoring_with_Dashboard_v2_-_Lenz_Grimmer/) 和 [2018-JUN-06_-_-_Ceph_Developer_Monthly](/VideoSummary/2018/06/06/2018-JUN-06_-_-_Ceph_Developer_Monthly/)。

### 智能运维特性
- 讨论了通过收集 SMART 指标预测设备故障、崩溃报告自动上传至 Manager、智能故障报告等运维自动化方向。详见 [2018-JUN-06_-_-_Ceph_Developer_Monthly](/VideoSummary/2018/06/06/2018-JUN-06_-_-_Ceph_Developer_Monthly/)。

### QoS 支持
- SK Telecom 分享了基于 DM Clock 算法的 QoS 实现方案，引入优先级队列和最小-最大权重算法，支持预留、限制控制和比例共享三种 QoS 控制模式。详见 [Ceph_QoS_-_How_to_support_QoS_in_distributed_storage_system_-_Taewong_Kim](/VideoSummary/2018/04/23/Ceph_QoS_-_How_to_support_QoS_in_distributed_storage_system_-_Taewoong_Kim/)。

### 性能分析工具
- Intel 工程师介绍了基于分布式追踪的性能分析方法，利用"发生之前"关系和事件成本定位瓶颈，并展示了 Jupiter 可视化工具在 Ceph 集群中的应用。详见 [Pinpoint_Ceph_Bottleneck_Out_of_ClusterBehavior_Mists_-_Yingxin_Cheng](/VideoSummary/2018/04/23/Pinpoint_Ceph_Bottleneck_Out_of_Cluster_Behavior_Mists_-_Yingxin_Cheng/)。

## 三、重要决策与里程碑

### 版本发布
- **Mimic 版本**：4 月底进入代码冻结，预计三到四周内发布（约 5 月底）。Mimic 带来 PG 合并、自动缩放、集中配置管理等重要特性。详见 [2018-MAY-02_-_-_Ceph_Developer_Monthly](2018-MAY-02_-_Ceph_Developer_Monthly)。
- **Luminous 版本**：作为当前稳定版本，多个用户案例（CERN、Flipkart、OVH 等）均基于 Luminous 部署。

### 重大设计决定
- 确定以 Bitmap Allocator 替换旧的 B 树分配器作为 BlueStore 的磁盘空间分配方案。
- 确定 BlueStore 优先级缓存方案，解决 BlueStore 与 RocksDB 缓存竞争问题。
- 确定 RGW 从 CivetWeb 迁移至 Beast HTTP 前端。
- 确定 Dashboard 作为 Open Attic 的官方替代品，逐步迁移其功能。
- 确定 Rook 作为 Ceph 在 Kubernetes 上的官方编排方案，并将 CSI 插件支持列入路线图。详见 [Making_Ceph_Awesome_on_Kubernetes_with_Rook_-_Bassam_Tabbara](/VideoSummary/2018/04/23/Making_Ceph_Awesome_on_Kubernetes_with_Rook_-_Bassam_Tabbara/)。

### 部署工具
- DepSea（基于 Salt 的 Ceph 部署框架）完成了五阶段部署流程的设计，支持自动化节点角色分配和集群配置管理。详见 [DepSea_-_Deployment_and_Management_of_Ceph_with_Salt_-_Joshua_Schmid](/VideoSummary/2018/04/23/DeepSea_-_Deployment_and_Management_of_Ceph_with_Salt_-_Joshua_Schmid/)。

## 四、社区动态

### 用户案例与生产实践
本季度有多个大规模生产用户分享了实践经验：

- **CERN**：拥有 8 个生产集群、近 6PB 存储，使用 Ceph 支撑 LHC 实验数据存储，提出了 RBD 性能监控工具、CephFS 并行 I/O 改进、池级别对象备份等改进需求。详见 [Ceph_for_Big_Science_-_Dan_van_derSter](/VideoSummary/2018/04/23/Ceph_for_Big_Science_-_Dan_van_der_Ster/)。
- **Flipkart**：印度最大电商，部署近三年，两个数据中心约 2000 台主机，分享了写入压力、元数据问题、应用错误、数据丢失等生产故障的排查与解决经验。详见 [Petabyte_Scale_Object_Storage_Service_Using_Ceph_in_A_Private_Cloud_-_Varada_Kari](/VideoSummary/2018/04/23/Petabyte_Scale_Object_Storage_Service_Using_Ceph_in_A_Private_Cloud_-_Varada_Kari/)。
- **OVH**：约 150 个集群、150 台服务器、44PB 存储容量，分享了缓存优化（PID 黑名单）、块大小匹配、XFS 死锁修复等经验。详见 [Running_Ceph_on_Flashcache_-_Pawe_Sadowski](/VideoSummary/2018/04/23/Running_Ceph_on_Flashcache_-_Pawe_Sadowski/)。
- **Rutherford Appleton 实验室**：分享了在 LHC 实验中使用纠删码（Erasure Code）的大规模实践，包括 CRUSH 映射调优、PG 回填性能问题的解决。详见 [Erasure_Code_at_Scale_-_Thomas_William_Byrne](/VideoSummary/2018/04/23/Erasure_Code_at_Scale_-_Thomas_William_Byrne/)。
- **SUSE**：分享了与 Ceph 合作 4-5 年的历程，以及 SAP 使用 Ceph 作为云原生平台核心存储的案例。详见 [Ceph_s_journey_at_SUSE_-_Lars_Marowsky_Bree_Marc_Koderer](/VideoSummary/2018/04/23/Ceph_s_journey_at_SUSE_-_Lars_Marowsky_Bree_Marc_Koderer/)。

### 会议与活动
- 本季度举办了 Ceph Tech Talk（Rook 专题）、两场 BlueStore Code Walkthrough、开发者月度会议（4 月、5 月、6 月）、性能周会（每周）、测试周会（每周）等系列活动。
- 通知了即将举办的软件定义存储会议，鼓励社区成员提交论文。
- 发布了 Ceph 用户调查，收集社区反馈。

### 贡献者活动
- Intel 在性能优化（NVM 编程模型、压缩加密、分布式追踪）方向持续贡献。详见 [Extending_Ceph_s_Reach_-_Tushar_Gohad_Zhong_Xin](/VideoSummary/2018/04/23/Extending_Ceph_s_Reach_-_Tushar_Gohad_Zhong_Xin/)。
- SK Telecom 贡献了 QoS（DM Clock）相关实现。
- Red Hat 主导了 Dashboard v2、DepSea、CephFS 等核心组件的开发。
- Rook 团队（Bassam Tabbara 等）推动 Ceph 与 Kubernetes 的深度集成。

## 五、下季度展望

基于本季度的讨论内容，预计 2018 Q3 将重点推进以下方向：

1. **Mimic 正式发布与稳定化**：Mimic 版本在 Q2 末发布后，Q3 将进入稳定维护阶段，社区将跟进生产环境反馈并发布修复版本。

2. **Nautilus 特性开发提速**：消息协议更新（msgr2）、Kerberos 集成、PG 自动合并与缩放、REST API 正式化等 Nautilus 目标特性将进入实质性开发阶段。

3. **BlueStore 优先级缓存落地**：优先级缓存 PR 完成测试后将合并，BlueStore 内存管理将更加智能化，OSD 内存目标自动调优有望在 Nautilus 中实现。

4. **Dashboard v2 功能完善**：NFS Ganesha 管理、iSCSI 目标管理等功能将从 Open Attic 迁移至 Dashboard，REST API 将进一步完善。

5. **Rook 生产就绪**：Rook 将推进 CSI 插件支持、多后端存储支持（MinIO、CockroachDB 等）和更智能的升级策略，向生产就绪目标迈进。

6. **测试框架成熟化**：Teuthology 的 libcloud 后端、OVH 测试环境、RGW 自动化测试套件将在 Q3 完成集成，提升 CI/CD 覆盖率。

7. **智能运维能力**：SMART 设备故障预测、崩溃报告自动化、集群健康状态改进等运维智能化特性将进入实现阶段。
