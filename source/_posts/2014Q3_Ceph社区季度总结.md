# Ceph 社区 2014Q3 季度进展报告

## 1. 本季度重点议题

本季度的核心主题围绕 **Ceph 的生态扩展与性能优化**展开，以下方向在多篇材料中反复出现：

**高性能网络集成**
网络层的性能瓶颈是本季度最突出的议题。[RH_InkTank_Ceph_Day_Sessions_Asaf_Wachtel_MELANOX](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Asaf_Wachtel_MELLANOX/) 和 [RH_InkTank_Ceph_Day_Sessions_Matt_Benjamin_COHORTFS](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Matt_Benjamin_COHORTFS/) 均从不同角度探讨了如何突破网络层限制——前者聚焦于 40/56Gbps 以太网硬件，后者聚焦于 RDMA/Infiniband 软件栈（Acelio/XIO）。

**Ceph 与 OpenStack 生态融合**
[RH_InkTank_Ceph_Day_Sessions_Kamesh_Pemaraju_DELL](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Kamesh_Pemmaraju_DELL/) 详细讨论了 Ceph 作为 OpenStack 底层存储平台的落地路径，这一方向在本季度具有明显的商业推动力。

**元数据扩展性**
[RH_InkTank_Ceph_Day_Sessions_Casey_Bodley_COHORTFS](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Casey_Bodley_COHORTFS/) 专门讨论了 NFS 元数据扩展性问题，pNFS metastripe 方案被提出作为解决 CephFS 元数据瓶颈的路径之一。

**存储硬件创新**
[RH_InkTank_Ceph_Day_Sessions_Mario_Blandini_HGST](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Mario_Blandini_HGST/) 展示了 HGST 的开放以太网驱动架构，代表了硬件厂商围绕 Ceph 进行深度定制的趋势。

## 2. 技术亮点

### 2.1 Acelio/XIO Messenger 集成

[RH_InkTank_Ceph_Day_Sessions_Matt_Benjamin_COHORTFS](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Matt_Benjamin_COHORTFS/) 介绍了与 Melanox 合作将 Acelio 高性能消息库集成进 Ceph 的进展：

- XIO Messenger 作为 Accelio 的适配层，将 Ceph 消息传递映射到 Infiniband
- 支持零拷贝（zero-copy）、内部消息路径几乎无锁
- 在 64K 消息大小下几乎饱和 XIO 可用带宽
- Ceph 代码库正在重构以提取通用消息传递接口，使所有 Messenger 实现可复用公共代码
- 代码已提交至 Acelio 和 Ceph 的 GitHub 仓库

### 2.2 pNFS Metastripe 元数据扩展方案

[RH_InkTank_Ceph_Day_Sessions_Casey_Bodley_COHORTFS](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Casey_Bodley_COHORTFS/) 提出了将 pNFS 思想应用于元数据的新技术：

- 定义两种布局类型：文件条带布局（file stripe layout）和目录条带布局（directory stripe layout）
- 客户端通过初始 MDS 获取布局信息后可直接访问其他 MDS，减少单点压力
- 支持并行读取、并行目录修改和布局提交（layout commit）
- 原型基于开源 NFS Ganesha 服务器和 pNFS 测试套件实现
- IETF 草案正在推进中

### 2.3 Gluster + Ceph 混合实验（GLaDOS）

[RH_InkTank_Ceph_Day_Sessions_Jeff_Darcy_REDHAT](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Jeff_Darcy_REDHAT/) 展示了 Red Hat 内部将 Gluster 翻译器层与 Ceph RADOS 后端结合的实验性探索：

- 将 Gluster 文件与对应 RADOS 对象关联，实现存储后端可切换
- 4K 同步随机写入测试中，GLaDOS 版本性能优于 CephFS（CephFS）
- 低线程计数下存在性能劣势，原因待进一步调查
- 明确定性为实验性探索，非官方路线图

### 2.4 HGST 开放以太网驱动架构

[RH_InkTank_Ceph_Day_Sessions_Mario_Blandini_HGST](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Mario_Blandini_HGST/) 展示了面向软件定义存储的新硬件形态：

- 3.5 英寸 HDD 内置以太网接口，支持 10GbE
- 60 盘位机架服务器集成交换机
- 原生支持 Ceph、Gluster、OpenStack 软件栈
- 将计算能力下沉至存储介质侧，减少主机 CPU 开销

## 3. 重要决策与里程碑

### 3.1 Red Hat 收购 Inktank 后的战略定位

[RH_InkTank_Ceph_Day_Sessions_Sage_Weil_REDHAT](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Sage_Weil_REDHAT/) 由 Ceph 项目创始人 Sage Weil 系统梳理了项目发展脉络，并明确了 Red Hat 阶段的战略重点：

- **分层存储（Tiering）**：引入缓存池（cache pool）和分层架构，实现冷热数据分离
- **纠删码（Erasure Coding）**：降低存储成本，提升数据可靠性
- **多数据中心（Multi-datacenter）**：异步复制与灾难恢复能力
- **CephFS 生产化**：提升文件系统稳定性，推进至生产级（production-ready）状态
- 计划建立项目委员会，完善治理结构

### 3.2 Dell + Red Hat 联合解决方案

[RH_InkTank_Ceph_Day_Sessions_Kamesh_Pemmaraju_DELL](/VideoSummary/2014/07/25/RH_InkTank_Ceph_Day_Sessions_Kamesh_Pemmaraju_DELL/) 宣布 Dell 与 Red Hat 将推出预配置的 Ceph + OpenStack 联合解决方案，标志着 Ceph 在企业级市场的商业化进程加速。

## 5. 下季度展望

基于本季度讨论内容，预计后续工作将集中在以下方向：

**XIO Messenger 主线合并**
Accelio 集成已完成基础验证，下一步是将 XIO Messenger 合并进 Ceph 主分支，并完成集群级别的端到端测试。Ceph 消息传递层的重构也将随之推进。

**CephFS 生产化推进**
Sage Weil 明确将 CephFS 稳定性列为优先项，pNFS metastripe 的 IETF 草案推进和 Seth frag trees 支持将是具体抓手。

**纠删码与分层存储完善**
这两项功能在本季度被列为当前工作重点，预计将在后续版本中进一步完善并推向生产可用状态。

**OpenStack 深度集成**
Dell + Red Hat 联合方案的落地、Cinder/Glance/Nova 与Ceph 的集成优化，将是企业级市场的主要推动力。

**硬件生态标准化**
HGST 开放以太网驱动架构若获得社区认可，可能推动 Ceph 对计算下沉（disagregated storage）架构的原生支持探索。
