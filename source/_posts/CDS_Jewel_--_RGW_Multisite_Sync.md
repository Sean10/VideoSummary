### 会议纪要

**会议主题**： Ceph RGW 多站点同步配置改进

**会议时间**： 未提及

**参会人员**： 未提及

**会议内容**：

**一、多站点配置蓝图概述**

1. **新区域（Realm）**： 引入区域概念，当前系统视为单个区域，未来可支持多区域。
2. **新周期（Period）**： 引入周期概念，确保在达到 Must Run 区域时，不会丢失数据和信息。
3. **元数据同步**：
    - 主节点上执行元数据操作并锁定。
    - 从节点应用更改前同步元数据日志。
    - 保留元数据版本向量，记录周期变化。
4. **数据同步**：
    - 使用与元数据同步相同的方法进行数据同步。
    - 改进同步效率，可选全量同步或快速同步。
5. **主动-主动复制（Active-Active Replication）**：
    - 实现网关内部的主动-主动复制。
    - 支持跨多个区域进行复制，使用时间戳和名称作为决断条件。
6. **网关代理**：
    - 移除网关代理，将代理功能集成到网关中，提高效率并简化配置。
7. **推送通知**：
    - 添加推送通知功能，将最近发生的更改立即通知相关区域。

**二、讨论的主要议题**

1. 元数据同步和数据同步的改进方案。
2. 主动-主动复制的设计和实现。
3. 网关代理的集成和功能优化。

**三、决定的事项**

1. 采用新周期概念，确保数据同步的可靠性。
2. 在网关内部实现主动-主动复制。
3. 移除网关代理，将代理功能集成到网关中。
4. 添加推送通知功能，提高数据同步的效率。

**四、后续行动计划**

1. 完成元数据同步和数据同步的改进方案设计。
2. 开发主动-主动复制功能。
3. 集成网关代理功能。
4. 实现推送通知功能。

**五、其他**

1. 讨论并解决不同区域之间的冲突和数据一致性保证。
2. 优化数据同步效率。
3. 制定详细的开发计划和时间表。
