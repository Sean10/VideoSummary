## 概述

本次技术分享由 Ceph 社区经理兼 Ambassador 项目负责人 Anthony Middleton 主讲，围绕 Ceph Foundation Ambassador Program 的定义、目标、现状及 2026 年行动计划进行了系统性介绍，旨在吸引更多社区成员参与并推动 Ceph 社区在全球各地区的持续增长。

## 什么是 Ceph Ambassador Program

Ceph Ambassador Program 是 Ceph Foundation 设立的一项社区认可机制，旨在表彰并支持那些积极参与社区活动的个人。Ambassador 的核心职责包括：

- **社区教育**：帮助他人了解 Ceph 是什么，以及它能解决哪些问题
- **活动组织**：协助组织和支持本地 Ceph 相关活动，如 Ceph Days、Ceph Meetups
- **跨社区联络**：作为 Ceph 与其他开源社区之间的桥梁，推动跨生态合作
- **反馈传递**：将地区用户的声音和需求反馈给 Ceph Foundation 领导层

Ambassador 来自各行各业，包括 operators、architects、contributors 和社区建设者，他们分布在全球多个活跃地区，代表 Ceph 在当地发声。

## Ambassador Program 的四大核心目标

### 1. 建设地区社区（Build Regional Communities）

通过组织 Ceph Days 和 Ceph Meetups，扩大本地 operator 网络。Ambassador 还被鼓励参与其他开源社区的活动，探索与 Ceph 的潜在合作机会。Anthony 表示，如果有任何关于跨社区合作的疑问，可以直接联系他，他愿意协助牵线搭桥。

### 2. 放大用户声音（Amplify User Voices）

收集 Ceph 用户故事，展示真实使用场景，帮助更多人了解 Ceph 的实际价值，从而吸引更多用户加入社区。

### 3. 提升 Ceph 知名度（Increase Ceph Visibility）

通过社交媒体倡导和跨社区合作提升 Ceph 的曝光度。目前 Ceph 已与 OpenInfra、Kubernetes 等生态建立了连接，Ambassador 可以在这些社区的活动中代表 Ceph 发声。

### 4. 支持上游参与（Support Upstream Engagement）

鼓励新贡献者加入，推动大学外联计划，并积极参与 **Google Summer of Code** 导师/学员项目。Ceph Foundation 已连续近 10 年参与 Google Summer of Code，今年再次获批参与资格。目前仍有机会报名成为导师，学员申请通道将于三月底开放。

## 2025 年经验总结

Anthony 于 2025 年正式加入 Ceph Foundation 担任社区经理，在与 Ambassador的多次会议中收集到以下核心需求：

- **标准化活动物料**：Ambassador 希望有统一的宣传卡片，包含 QR code，方便在活动现场向陌生人介绍 Ceph
- **清晰的资金申请路径**：需要更透明的经费支持流程
- **更多面向用户的内容**：希望增加针对 Ceph 新手的工作坊，帮助用户了解如何搭建 storage cluster
- **更好的沟通工具**：改进邮件列表、社交媒体运营及 Slack 工具的使用体验

## 资金支持机制

Ceph Foundation 设有专项资金申请通道，面向所有社区成员（不限于 Ambassador）。申请场景包括：

- 参加 Ceph 相关会议
- 组织 Ceph Days 或 Ceph Meetup
- 在会议上发表演讲

申请表格可通过演讲中展示的 QR code 访问，也可在 ceph.io 网站的 Community → Connect 页面找到。所有申请由 Ceph Foundation Governing Board 审核，无论批准或拒绝均会给出书面回复和说明。

## 新 Ambassador 招募要求

Ceph Foundation 正在积极招募新 Ambassador，理想候选人应具备：

- 在所在地区活跃参与社区活动
- 有意愿组织本地活动
- 能够与用户和 operators 有效沟通
- 关注上游开源社区的健康发展
- 对 Ceph 有一定了解，能够向他人介绍 Ceph

Anthony 特别强调，**不需要是顶级贡献者，也不需要来自 IBM、Bloomberg 等主要厂商**。即使仍在学习 Ceph，只要对社区建设充满热情，都欢迎申请。

## 2026 年行动号召

基于与 Ceph Foundation Governing Board 及现有 Ambassador 的讨论，2026 年的重点行动方向包括：

1. **收集更多 Ceph 用户故事**：记录真实使用案例，扩大 Ceph 影响力
2. **加强大学外联**：与高校数据科学项目建立连接，推动 Ceph 进入学术圈
3. **推动更多地区举办 Ceph Days**：近期计划包括 Ceph Days India（下月）、Ceph Days Raleigh（北卡罗来纳州），以及两场 Ceph Meetup
4. **深化跨生态合作**：与 OpenInfra、Kubernetes 等已有连接的开源项目进一步协作，共建社区

## 如何参与

有意加入 Ambassador Program 的社区成员可以：

1. 直接联系 Anthony Middleton（邮件或 Slack：Anthony Middleton，LinkedIn 同名）
2. 扫描演讲中的 QR code 填写 SEF Community Database 申请表，选择 Ambassador Program
3. 从小事做起：举办一次 Meetup、撰写一篇博客、收集用户故事，或协助组织 Ceph Day

活动信息可关注 ceph.io/community/events，以及 LinkedIn、Twitter、Bluesky 和邮件列表。

## 问答环节

- **演讲录像和 PPT 将发布在 ceph.io 网站的 Tech Talks 页面**，可在 Community栏目下找到
- Tech Talk 计划以**每月一次**的频率举行，欢迎社区成员提议话题或申请演讲
- 演讲日程同样可在 ceph.io 网站查询

## 总结

Ceph 的成长依赖于每一位社区成员的投入。Ambassador Program 是 Ceph Foundation 连接全球用户、推动地区社区发展的重要机制。无论技术背景深浅，只要对 Ceph 和开源社区充满热情，都有机会成为 Ambassador，共同塑造 Ceph 的未来。
