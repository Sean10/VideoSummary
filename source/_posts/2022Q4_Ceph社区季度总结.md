# Ceph 社区季度进展报告：2022 Q4

## 1. 本季度重点议题

本季度 Ceph 社区围绕以下几个核心方向持续深入讨论：

**Crimson/SeaStore 稳定化与功能完善**
Crimson OSD 作为下一代高性能存储引擎，本季度在多核支持、快照实现、用户保护机制等方面取得重要进展，是贯穿整个季度的核心议题。详见 [What_s_new_with_Crimson_and_Seastore](/VideoSummary/2022/11/10/What_s_new_with_Crimson_and_Seastore/) 和 [Ceph_Crimson_Seastore_Meeting_2022-10-19](/VideoSummary/2022/10/20/Ceph_Crimson_Seastore_Meeting_2022-10-19/)。

**BlueStore 性能优化**
BlueStore 的写路径优化、共享 blob 处理、RocksDB tombstone 问题、4K 分配单元等议题在多次性能会议中反复出现，是本季度性能方向的主线。

**RGW 重构（Zipper 架构）**
RGW 的模块化重构持续推进，Zipper API 框架、依赖管理、代码清理等议题贯穿整个季度的 RGW 重构会议。

**Reef 版本准备**
多个子系统的开发工作明确以 Reef 版本代码冻结为节点目标，包括 Crimson 功能完善、Scrub 调度改进、新工作负载平衡器等。

---

## 2. 技术亮点

### Crimson / SeaStore

- **多核心支持**：实现了数据结构分区和消息路由架构，[Ceph_Crimson_SeaStore_Meeting_2022-12-07](/VideoSummary/2022/12/07/Ceph_Crimson_SeaStore_Meeting_2022-12-07/) 中讨论了 IO Handler 类的实现，将消息握手从同步转为异步以支持跨核心通信。分布式对象存储相较于单节点性能提升超过 10%。
- **快照支持**：基本 I/O 路径组件已实现，修剪（pruning）和恢复组件正在进行中，详见 [What_s_new_with_Crimson_and_Seastore](/VideoSummary/2022/11/10/What_s_new_with_Crimson_and_Seastore/)。
- **用户保护机制**：[Ceph_Developer_Monthly_2022-11-02](/VideoSummary/2022/11/23/Ceph_Developer_Monthly_2022-11-02/) 中引入了两种保护措施——实验性功能标志和 OSD map 标志，防止用户意外在生产集群中启动 Crimson OSD。
- **SeaStore 性能分析**：[Understanding_SeaStore_through_profiling](/VideoSummary/2022/11/14/Understanding_SeaStore_through_profiling/) 详细介绍了通过引入超过 1000 个指标和 28 个 PR 进行性能分析，15 个 PR 用于实际优化的系统性工作方法。
- **ZNS 支持**：[Ceph_Crimson_SeaStore_Meeting_2022-08-16](/VideoSummary/2022/10/20/Ceph_Crimson_SeaStore_Meeting_2022-08-16/) 中 Aaron 提交了 GNS 补丁第二版，并在物理 ZNS 驱动上进行测试。

### BlueStore 与存储性能

- **共享 blob 优化**：[Ceph_Performance_Meeting_2022-11-17](/VideoSummary/2022/11/17/Ceph_Performance_Meeting_2022-11-17/) 中 Adam 致力于改进 BlueStore 中共享 blob 的处理方式，特别是快照场景下的性能，考虑将新 extent 添加到现有共享 blob 而非创建新的。
- **RocksDB tombstone 问题**：[Ceph_Performance_Meeting_2022-08-18](/VideoSummary/2022/10/20/Ceph_Performance_Meeting_2022-08-18/) 讨论了在 KV 层自行跟踪删除操作、手动触发压缩或刷新的方案。
- **BlueFS 4K 分配单元**：[Ceph_Performance_Meeting_2022-12-08](/VideoSummary/2022/12/08/Ceph_Performance_Meeting_2022-12-08/) 提出了 BlueFS 启用 4K 分配单元的 PR，并讨论了 BlueStore 中 AVL 和混合分配器加速方案。
- **Deferred Writes优化**：[Ceph_Performance_Meeting_2022-10-20](/VideoSummary/2022/10/20/Ceph_Performance_Meeting_2022-10-20/) 讨论了完全移除 Deferred Writes 路径的可能性。
- **PMEM 硬件卸载**：[Accelerating_PMEM_Device_operationsin_bluestore_with_hardware_based_memory_offloading_technique](/VideoSummary/2022/11/14/Accelerating_PMEM_Device_operations_in_bluestore_with_hardware_based_memory_offloading_technique/) 介绍了利用 Intel DSA（数据流加速器）减轻 CPU 在持久内存操作中的压力，已在 BlueStore 中实现同步模式支持。

### RGW 重构

- **Zipper 架构**：[RGW_Zipper](/VideoSummary/2022/11/15/RGW_Zipper/) 详细介绍了将 RGW 协议层与存储层解耦的三层架构，通过 Zipper API 支持可插拔存储后端和堆叠过滤器，已被 Seagate、Intel 和 SUSE 采用。
- **多对象删除优化**：[Ceph_RGW_Refactoring_Meeting_2022-11-02](/VideoSummary/2022/11/02/Ceph_RGW_Refactoring_Meeting_2022-11-02/) 讨论了并发协程限制和 QoS 配置参数，以避免对集群造成过大 IOPS 压力。
- **Object Lambda**：[Ceph_RGW_Refactoring_Meeting_2022-11-23](/VideoSummary/2022/11/23/Ceph_RGW_Refactoring_Meeting_2022-11-23/) 探讨了对象 Lambda 功能，分析了内联处理与离线处理的权衡，以及与 Spark 等大数据生态系统的集成方向。
- **S3 Select 计算存储**：[S3select_-_Computational_Storage_in3](/VideoSummary/2022/11/14/S3select_-_Computational_Storage_in_S3/) 介绍了将 SQL 查询推送到存储层的实现，支持 CSV、JSON、Parquet 格式，并规划与 Spark、Presto 的集成。
- **存储类与 Lua 脚本**：[Optimizing_RGW_Object_Storage_Mixed_Media_through_Storage_Classes_and_Lua_Scripting](/VideoSummary/2022/11/10/Optimizing_RGW_Object_Storage_Mixed_Media_through_Storage_Classes_and_Lua_Scripting/) 展示了通过 Lua 脚本根据对象大小自动路由到不同存储池（TLC/QLC）的混合媒体优化方案。

### 新特性与工具

- **新工作负载平衡器**：[New_workload_balancer_in_Ceph](/VideoSummary/2022/11/15/New_workload_balancer_in_Ceph/) 介绍了 Reef 版本中即将引入的读取感知平衡器，通过改变 PG 的主OSD 而不移动数据来优化小型集群的读取均衡。
- **NVMe-oF Gateway**：[NVMe-over-Fabrics_support_forCeph](/VideoSummary/2022/11/23/NVMe-over-Fabrics_support_for_Ceph/) 展示了基于 SPDK 的 Ceph NVMe over Fabrics Gateway 实现，支持 gRPC API 配置管理。
- **COSI 接口**：[Introduction_to_Container_Object_Storage_Interface_aka_COSI_for_ceph_RGW](/VideoSummary/2022/11/23/Introduction_to_Container_Object_Storage_Interface_aka_COSI_for_ceph_RGW/) 介绍了 Kubernetes 容器对象存储接口的 Ceph RGW 驱动，目前处于 alpha 阶段。
- **Crash Telemetry**：[Ceph_Crash_Telemetry_-_Observability_in_Action](/VideoSummary/2022/11/09/Ceph_Crash_Telemetry_-_Observability_in_Action/) 展示了崩溃遥测系统的完整流程，包括自动将崩溃签名映射到 Redmine 问题的 bot。
- **Scrub 调度改进**：[Ceph_Developer_Monthly_2022-12-07](/VideoSummary/2022/12/07/Ceph_Developer_Monthly_2022-12-07/) 中 Ronin 提出引入 Scrub Target 和 Urgency 字段，优化调度逻辑，提高代码可维护性。
- **Manager 架构提案**：[Ceph_Developer_Monthly_2022-10-05](/VideoSummary/2022/10/05/Ceph_Developer_Monthly_2022-10-05/) 提出通过 gRPC 服务器将 Manager 模块移至独立进程，消除 Python GIL 限制，提高并发处理能力。

## 3. 重要决策与里程碑

**Reef 版本功能规划确定**
本季度多个会议明确了 Reef 版本的功能边界：Crimson 将增加多反应器支持并改进可用性，新工作负载平衡器将作为离线工具提供，Scrub 调度将得到重构。[State_of_the_Cephalopod_2022](/VideoSummary/2022/11/09/State_of_the_Cephalopod_2022/) 对整体路线图进行了系统性梳理。

**Crimson 用户保护机制落地**
正式引入 OSD map 标志和实验性功能标志，防止 Crimson OSD 意外进入生产集群，这是 Crimson 走向可用性的重要里程碑。

**Ceph 治理结构调整**
[State_of_the_Cephalopod_2022](/VideoSummary/2022/11/09/State_of_the_Cephalopod_2022/) 确认项目创始人 Sage Weil 逐渐退出日常管理，项目转由 Ceph 领导团队和选举产生的执行委员会共同治理，领导团队会议对所有人开放。

**RGW Zipper 架构被多家厂商采用**
Zipper 架构已被 Seagate、Intel 和 SUSE 采用并集成，标志着 RGW 模块化重构取得实质性进展。

**大规模生产验证**
[How_we_operateCeph_at_scale](/VideoSummary/2022/11/10/How_we_operate_Ceph_at_scale/) 中 DigitalOcean 披露运营 46 个 Ceph 集群（38 个生产集群），总存储容量超过 140PB，验证了 Ceph 在超大规模场景下的可行性。

**Quincy 版本大规模测试完成**
在澳大利亚 Pawsey 超级计算中心完成了 4000 个 OSD 的测试，以及逻辑规模大型集群模拟测试。

## 4. 社区动态

**Cephalocon 虚拟会议**
本季度举办了虚拟 Cephalicon 会议，多篇技术演讲涵盖了 BlueStore 优化、RGW 重构、Crimson 进展、安全加固、大规模运营实践等主题，体现了社区的广泛参与。

**开发者月度会议**
[Ceph_Developer_Monthly_2022-10-05](/VideoSummary/2022/10/05/Ceph_Developer_Monthly_2022-10-05/)、[Ceph_Developer_Monthly_2022-11-02](/VideoSummary/2022/11/23/Ceph_Developer_Monthly_2022-11-02/)、[Ceph_Developer_Monthly_2022-12-07](/VideoSummary/2022/12/07/Ceph_Developer_Monthly_2022-12-07/) 三次月度会议持续进行，覆盖了 Dashboard 可访问性改进、Crimson 保护机制、Scrub 调度、依赖管理等议题。

**Open Source Day活动**
[Ceph_Orchestrator_Meeting_2022-09-13](/VideoSummary/2022/10/12/Ceph_Orchestrator_Meeting_2022-09-13/) 中提到 9 月 16 日举办了 Open Source Day，邀请参与者解决低难度技术问题，吸引新贡献者参与。

**新贡献者引入**
[Ceph_Crimson_SeaStore_Meeting_2022-12-07](/VideoSummary/2022/12/07/Ceph_Crimson_SeaStore_Meeting_2022-12-07/) 中有新成员加入 Crimson 团队，参与测试工作。[Ceph_RGW_Refactoring_Meeting_2022-11-30](/VideoSummary/2022/11/30/Ceph_RGW_Refactoring_Meeting_2022-11-30/) 中为新开发者提供了 RGW 入门文档和开发环境指引。

**Ceph 基金会健康运营**
[State_of_the_Cephalopod_2022](/VideoSummary/2022/11/09/State_of_the_Cephalopod_2022/) 确认基金会维持 10 个主要成员、13 个普通成员和 11 个关联成员的健康结构，负责协调活动和资助上游测试实验室。

**安全与合规关注**
[Data_Security_and_Storage_Hardening_In_Rook_and_Ceph](/VideoSummary/2022/11/15/Data_Security_and_Storage_Hardening_In_Rook_and_Ceph/) 中 Red Hat 团队系统性介绍了 Rook/Ceph 的安全加固实践，包括网络分区、加密、身份管理、审计日志等，反映了社区对企业级安全需求的重视。

**Telemetry 参与推广**
社区持续鼓励用户加入 Telemetry 服务，Crash Telemetry 已成功自动发现并推动修复多个问题，Telemetry bot 自动将崩溃报告映射到 Redmine 问题的机制运转良好。

## 5. 下季度展望

基于本季度的讨论内容，预计 2023 Q1 将重点推进以下方向：

**Reef 版本冲刺**
Reef 代码冻结临近，Crimson 多反应器支持、快照功能完善、Scrub 重构、新工作负载平衡器等功能将进入最终集成阶段。[Ceph_Crimson_Seastore_Meeting_2022-10-19](/VideoSummary/2022/10/20/Ceph_Crimson_Seastore_Meeting_2022-10-19/) 明确提到"Reef 代码冻结前"作为关键节点。

**Crimson 性能测试启动**
随着 Crimson 功能稳定化工作接近完成，性能测试将成为下一阶段重点，多核心反应器支持完成后将进行系统性能对比测试。

**RGW 重构深化**
Zipper 可加载插件工作预计在一个月内完成，Lua 过滤器开发将启动，Object Lambda 外部处理方案将继续评估。

**BlueStore 架构演进讨论**
[Ceph_Performance_Meeting_2022-11-03](/VideoSummary/2022/11/09/Ceph_Performance_Meeting_2022-11-03/) 中已开始讨论 BlueStore 2的可能性，包括改进写路径和分层存储支持，预计下季度将有更多架构层面的讨论。

**NVMe-oF Gateway 功能完善**
Gateway 组、多路径支持、发现服务、认证加密等功能已在路线图中，下季度将持续推进。

**S 版本命名与规划启动**
[State_of_the_Cephalopod_2022](/VideoSummary/2022/11/09/State_of_the_Cephalopod_2022/) 提到即将开始 S 版本的命名讨论，下季度社区将启动下一个大版本的早期规划工作。
