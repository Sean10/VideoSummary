# Ceph 社区 2021Q1 季度进展报告

---

## 1. 本季度重点议题

本季度 Ceph 社区围绕以下几个核心方向持续深入讨论：

**Crimson/SeaStore 新一代 OSD 开发**
Crimson OSD 和 SeaStore 存储引擎是本季度最活跃的开发方向，贯穿整个季度的多次周会。核心议题包括客户端请求序列化、并发优化、垃圾回收器改进以及单元测试体系建设。详见 [Ceph Crimson 2021-23](/VideoSummary/2021/02/26/Ceph_Crimson_2021-02-23/)、[Ceph Crimson SeaStore 2021-03-10](/VideoSummary/2021/03/10/Ceph_Crimson_SeaStore_2021-03-10/)、[Ceph Crimson SeaStore 2021-03-17](/VideoSummary/2021/03/18/Ceph_Crimson_SeaStore_2021-03-17/)、[Ceph Crimson Seastore 2021-03-23](/VideoSummary/2021/03/26/Ceph_Crimson_Seastore_2021-03-23/)。

**Pacific 版本发布冲刺**
Pacific 是本季度最重要的里程碑，多个会议中均提及 Pacific 的阻塞问题修复和发布准备工作。

**Orchestrator 与 Cephadm 多站点管理**
RGW 多站点配置、NFS 服务管理、HA RGW 架构设计等 Orchestrator 层面的功能在本季度密集讨论。

**BlueStore/OMAP 性能优化**
BlueStore 的 OMAP 性能瓶颈、RocksDB 代码路径优化、缓存管理改进是性能方向的核心议题。

**Teuthology 测试基础设施**
本季度专门开展了多场 Teuthology 培训，覆盖框架介绍、测试开发和结果分析，反映社区对测试质量的重视。

---

## 2. 技术亮点

### Crimson/SeaStore

- **PG 流水线并行性 PR**：本季度完成测试，旨在提升 OSD 并发处理能力。详见 [Ceph Crimson SeaStore 2021-03-10](/VideoSummary/2021/03/10/Ceph_Crimson_SeaStore_2021-03-10/)。
- **垃圾回收器重构**：将 GC 从每个事务的内置操作改为独立并发任务，简化了 GC 状态机，预期解决之前观察到的崩溃问题。详见 [Ceph Crimson Seastore 2021-03-23](/VideoSummary/2021/03/26/Ceph_Crimson_Seastore_2021-03-23/)。
- **Alien Store 性能改进**：将 Alien Store 线程分散到不同 CPU 核心，改善多核利用率。
- **消息传递接口优化**：讨论并决定在 Crimson 中使用 `unique_ptr` 替代 `intrusive_ptr` 传递消息，提升内存安全性。详见 [Ceph Crimson SeaStore 2021-03-17](/VideoSummary/2021/03/18/Ceph_Crimson_SeaStore_2021-03-17/)。
- **客户端请求序列化器单元测试**：持续推进，确保请求持久化顺序与到达 OSD 的顺序一致。

### BlueStore 性能

- **动态 pen length PR合并**：解决了对齐问题，实测性能有所提升。
- **RocksDB 分配移除 PR**（Gaby 提交）：从 RocksDB 中移除分配操作，性能改进效果良好。
- **OMAP 基准测试工具**：新增快速 OMAP 基准测试 PR，支持写入多对象和大量键的时间测量。详见 [Ceph Performance Meeting 2021-03-11](/VideoSummary/2021/03/18/Ceph_Performance_Meeting_2021-03-11/)、[Ceph Performance Meeting 2021-03-25](/VideoSummary/2021/03/26/Ceph_Performance_Meeting_2021-03-25/)。
- **BlueFS Buffered I/O 优化**：讨论了将 BlueFS buffered I/O 设置为 true 的影响，相关 PR 已关闭并评估。

### RBD

- **librbd I/O 路径代码走读**：系统梳理了从 API 层到核心层的完整 I/O 路径，包括 QoS、独占锁、刷新状态机等可插拔层的设计。详见 [Ceph Code Walkthroughs - Librbd Part 2](/VideoSummary/2021/03/10/Ceph_Code_Walkthroughs_-_Librbd_Part_2/)。

### Orchestrator / Cephadm

- **HA RGW 服务架构**：提出将 HAProxy 和 Keepalived 拆分为两个独立服务，提升灵活性。详见 [Ceph Orchestrator Meeting 2021-03-23](/VideoSummary/2021/03/23/Ceph_Orchestrator_Meeting_2021-03-23/)。
- **RGW 配置上移至 Orchestrator 层**：统一管理 RGW 配置，避免 Rook 和 Cephadm 中的重复配置。详见 [Ceph Orchestrator Meeting 2021-03-30](/VideoSummary/2021/03/30/Ceph_Orchestrator_Meeting_2021-03-30/)。
- **OSD unmanaged 服务整合**：将所有非托管 OSD 整合到单一 OS 服务中。
- **网络/子网配置集成**：推进将网络和子网配置纳入服务规范（service spec）。

### Pacific 新特性（Sage Weil 介绍）

- 多文件系统支持、CephFS 异步链接操作
- RGW S3 Select 和 Lua 脚本集成
- 新的内存分配器和内存跟踪机制
- 改进的 QoS 和分布式追踪框架
- Cephadm 支持自动化升级和私有注册表认证

详见 [What's New in Pacific Ceph Release - Sage Weil](/VideoSummary/2021/03/09/What_s_New_in_Pacific_Ceph_Release_-_Sage_Weil/)。

## 3. 重要决策与里程碑

**Pacific 版本发布**
Pacific 预计于 2021 年 3 月发布，本季度多个会议均在推进阻塞问题的修复。[Ceph Crimson SeaStor OSD 2021-01-26](/VideoSummary/2021/01/27/Ceph_Crimson_SeaStor_OSD_2021-01-26/) 中提到修复了 ceph-adm 中被认定为 Pacific 发布阻塞点的问题。

**NFS v3 支持决策**
[Ceph Orchestrator Meeting 2021-03-11](/VideoSummary/2021/03/30/Ceph_Orchestrator_Meeting_2021-03-11/) 中讨论是否完全移除对 NFS 版本 3 的支持，决定通过邮件列表征求社区意见后再定。

**消息传递压缩方案**
[Ceph Developer Monthly 2021-02-03](/VideoSummary/2021/03/09/Ceph_Developer_Monthly_2021-02-03/) 中讨论了在 Messenger 层添加传输压缩的方案，决定在社区中进一步讨论，倾向于在数据负载层而非整个消息层进行压缩，以避免重复压缩开销。

**Teuthology 调度机制升级**
新的基于 Beanstalkd 优先队列的调度机制正式引入，解决了旧机制中的优先级反转问题。详见 [Teuthology Internals - Overview and Scheduling](/VideoSummary/2021/03/16/Teuthology_Internals_-_Overview_and_Scheduling/)。

**Quincy 版本规划启动**
Sage Weil 在 Pacific 介绍中提到，Quincy 版本规划即将开始，目标发布时间为 2022 年 3 月。

## 4. 社区动态

**开发者月度会议**
2021 年 2 月举办了开发者月度会议，讨论了跨服务指标共享、满载集群删除操作处理、消息传递压缩等跨组件议题。详见 [Ceph Developer Monthly 2021-02-03](/VideoSummary/2021/03/09/Ceph_Developer_Monthly_2021-02-03/)。

**Science Working Group**
科学用户工作组于 3 月举行非正式讨论，参与者主要为管理大型 Ceph 集群的用户，讨论了 MDS 内存问题、Nautilus 到 Octopus 升级计划，以及 Cephadm 在大规模集群中的性能问题。会议还规划了 **Ceph Month** 活动，作为 Cephalocon 的线上替代形式。详见 [Ceph Science Working Group 2021-03-24](/VideoSummary/2021/03/26/Ceph_Science_Working_Group_2021-03-24/)。

**Google Summer of Code**
[Ceph Orchestrator Meeting 2021-03-16](/VideoSummary/2021/03/30/Ceph_Orchestrator_Meeting_2021-03-16/) 中讨论了 GSoC 项目参与情况，社区成员将担任共同导师。

**Teuthology 培训系列**
本季度专门开展了三场 Teuthology 培训，系统覆盖框架介绍、测试开发方法和测试结果分析，旨在降低新贡献者的测试门槛。详见 [Teuthology Training - Introduction](/VideoSummary/2021/03/16/Teuthology_Training_-_Introduction/)、[Teuthology Training - Developing Tests](/VideoSummary/2021/03/16/Teuthology_Training_-_Developing_Tests/)、[Teuthology Training - Analyzing Test Results](/VideoSummary/2021/03/16/Teuthology_Training_-_Analyzing_Test_Results/)。

**代码走读系列**
librbd 代码走读第二部分在本季度举行，会议内容上传至 Ceph YouTube 频道，供社区成员学习参考。

---

## 5. 下季度展望

基于本季度的讨论内容，预计 2021Q2 将重点推进以下方向：

1. **Pacific 正式发布后的稳定化工作**：修复用户反馈的问题，推进 Nautilus/Octopus 用户向 Pacific 迁移。

2. **Crimson/SeaStore 功能完善**：PG 流水线并行性合并后的后续优化，SeaStore 未实现的 Future Store API 补全，以及更完整的单元测试覆盖。

3. **Orchestrator 功能落地**：HA RGW 服务拆分实施、VIP 服务放置规范扩展、网络配置集成到服务规范的开发和测试。

4. **BlueStore OMAP 性能持续优化**：`o_node_map` 数据结构优化方案落地，缓存管理简化方案实施。

5. **Quincy 版本早期规划**：开始收集需求，确定 Quincy 的核心特性方向。

6. **Ceph Month 活动举办**：以分散线上会议形式替代 Cephalocon，促进社区交流。
