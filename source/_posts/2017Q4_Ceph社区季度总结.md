# Ceph 社区 2017Q4 季度进展报告

## 1. 本季度重点议题

本季度 Ceph 社区围绕以下几个核心方向展开了深入讨论：

**OSD 架构重构**是本季度最突出的主题。两次开发者月度会议均涉及 OSD 层面的改进，包括模块化设计、异步事件驱动模型，以及 PG 日志的存储优化。详见 [2017-DEC-06_-_-_Ceph_Developer_Monthly](2017-DEC-06_-_Ceph_Developer_Monthly) 和 [2017-NOV-01_-_-_Ceph_Developer_Monthly](/VideoSummary/2017/12/18/2017-NOV-01_-_-_Ceph_Developer_Monthly/)。

**异步编程框架引入**同样贯穿本季度，包括 C++17 async 库的评估、C++ 协程的探索，以及 DPDK/SPDK 在网络和存储 IO 层的应用可能性。

**存储介质演进适配**：随着 NVMe 和全闪存部署的普及，社区开始系统性地讨论如何针对新介质特性优化 Ceph 的数据路径和日志机制。

---

## 2. 技术亮点

### PG 日志优化（[2017-NOV-01_-_-_Ceph_Developer_Monthly](/VideoSummary/2017/12/18/2017-NOV-01_-_-_Ceph_Developer_Monthly/)）

针对 SD 场景下 PG 日志带来的写放大、CPU 和内存开销问题，社区提出了两项具体改进：

- 在 SSD 上使用**环形缓冲区（Ring Buffer）**存储 PG 日志，降低写放大
- 引入 **FIFO 压缩模式**，简化数据结构、提升处理效率
- 将 PG 日志与其他内部元数据分离存储，减少内存占用

### 快照修剪（Snapshot Triming）改进

- 采用**增量数据结构**替代现有方案，降低 CPU 开销
- 将快照修剪逻辑与缓存淘汰（Cache Eviction）解耦，独立处理

### OSD 模块化与性能重构（[2017-DEC-06_-_-_Ceph_Developer_Monthly](/VideoSummary/2017/12/19/2017-DEC-06_-_-_Ceph_Developer_Monthly/)）

- 探索基于 **DPDK**（网络）和 **SPDK**（存储 IO）的高性能数据路径
- 减少数据结构中的不必要拷贝和内存分配，提升 CPU 利用率
- 讨论多种新型存储池模型：
  - 非复制池，直接写入 SPDK
  - 并行多副本写入池，支持不同一致性和容错模型
  - 面向 Fabrics 的池，直接在 Fabrics 层写入所有副本

### Ceph Manager 组件成熟

[Ceph_Promo_Video_2017](/VideoSummary/2017/11/06/Ceph_Promo_Video_2017/) 中明确介绍了 **Ceph Manager** 作为新组件的定位：承接分析 API 和管理功能，使 Monitor 专注于关键集群状态，从而支撑更大规模的集群部署。

### RGW 云同步功能

本季度提及了 RGW（Rados Gateway）的**云同步（Cloud Sync）**功能进展，支持跨数据中心、跨地理位置的集群联合，以及基于 ACL 的认证机制。

## 3. 重要决策与里程碑

| 决策 | 说明 |
|------|---|
| PG 日志环形缓冲区 | 确定在 SSD 场景下采用环形缓冲区 + FIFO 压缩模式 |
| 快照修剪算法重写 | 决定引入增量数据结构并优化修剪算法 |
| C++17 async 重构启动 | 决定开始将部分阻塞代码迁移至异步模式 |
| PT 合并方案讨论 | 确定需保证合并过程可逆，并对齐 PT 日志后再合并 |

**Ceph Dashboard** 开发项目在本季度由 Red Hat 推进，作为管理界面的重要组成部分被提及。

## 4. 社区动态

- **开发者月度会议（CDM）**：本季度至少举行了两次，分别在 11 月和 12 月，参与者包括 Greg、Josh、Sage、Mark、Adam、Casey 等核心贡献者，讨论议题覆盖 OSD 重构、PG 日志、快照修剪和异步框架。
- **Ceph 宣传视频发布**：[Ceph_Promo_Video_2017](/VideoSummary/2017/11/06/Ceph_Promo_Video_2017/) 系统性地介绍了 Ceph 的架构（RADOS、OSD、Monitor、Ceph Manager）及三大接口（RGW、RBD、CephFS），面向更广泛受众推广 Ceph 生态。
- **Red Hat 持续投入**：Red Hat 在本季度主导了 Ceph Dashboard 的开发，体现了商业力量对社区的持续贡献。

---

## 5. 下季度展望

基于本季度的讨论方向，预计 2018Q1 将重点推进以下工作：

1. **DPDK/SPDK 集成原型**：本季度已完成方向确认，下季度有望出现早期原型或 RFC
2. **C++17 async 重构落地**：代码重构已启动，预计将有更多模块完成异步化改造
3. **PG 日志环形缓冲区实现**：决策已定，实现和评估工作将在下季度展开
4. **Ceph Dashboard 功能完善**：Red Hat 主导的仪表板项目将持续迭代
5. **新型存储池模型 RFC**：多种池模型的讨论已较为成熟，预计进入正式提案阶段
6. **RGW 云同步功能推进**：跨数据中心同步能力将进一步完善
